## 2. 正式 NOV 的口径

对测试学生 u，令 `C(u)` 为其历史答对习题涉及的知识点集合，`K(Top-N,u)` 为推荐列表前 N 道习题知识点的并集。正式 `NOV` 为：

`mean_u [1 - |K(Top-N,u) ∩ C(u)| / |K(Top-N,u) ∪ C(u)|]`。

原主模型与对比模型评估都将此值同时写入 `NOV` 和 `KG4Ex-NOV-Set`。逐题计算后平均的 KG4Ex 指标仍单独写入 `KG4Ex-NOV`；旧时间加权指标写入 `NOV_time_weighted`。Ada、Ep 和公平性指标保留。这个指标变更仅重算评价，不更改训练损失或模型结构；新实验的汇总从 `NOV` 读取正式值。历史结果目录里的旧 `metrics.json` 不会被静默改写。
