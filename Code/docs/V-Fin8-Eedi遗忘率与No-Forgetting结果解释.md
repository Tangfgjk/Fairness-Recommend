# V-Fin8：Eedi 遗忘率定义与 No-Forgetting 结果解释

本文档回答关于 Eedi 数据集上遗忘关系 `forgetting` 的几个问题：

1. 只出现一次的习题，`forgetting rate` 是多少？没有出现过的习题是否也是 0？
2. 当前 `forgetting` 是如何给定和计算的？
3. Eedi 中每个学习者做题情况如何，是否存在大量“只出现一次”的题？
4. 为什么在 `N >= 30` 时，`No-Forgetting` 的结果反而更好？

## 1. Forgetting rate 不是按“题目出现次数”直接给定

当前代码中，遗忘率不是简单地根据一道题出现几次来设为 `0` 或 `1`，而是先在“学生-知识点”层面计算遗忘程度，再根据题目对应的知识点得到“学生-题目”遗忘程度。

也就是说，遗忘率的核心不是：

```text
这道题做过几次
```

而是：

```text
学生距离上一次接触该题所涉及知识点已经过去多久
```

## 2. 当前 forgetting 的计算方式

### 2.1 学生-知识点遗忘率

对于学生 `u` 和知识点 `k`，遗忘率定义为：

```text
forget(u, k) = 1 - exp(- Δt(u, k) / θ)
```

其中：

| 符号 | 含义 |
|---|---|
| `u` | 学生 |
| `k` | 知识点 |
| `Δt(u, k)` | 学生 `u` 最近一次接触知识点 `k` 到当前学习状态之间的间隔 |
| `θ` | 遗忘衰减参数 |

因此：

- 如果 `Δt(u, k) = 0`，说明该知识点刚刚被接触过，遗忘率为 `0`。
- 如果 `Δt(u, k)` 越大，说明该知识点距离上次接触越久，遗忘率越高。
- 遗忘率被限制在 `[0, 1]` 范围内。

### 2.2 学生-题目遗忘率

题目 `e` 可能对应一个或多个知识点。当前做法是将题目所涉及知识点的遗忘率取平均：

```text
forget(u, e) =
mean({ forget(u, k) | k ∈ KC(e) })
```

其中 `KC(e)` 表示题目 `e` 对应的知识点集合。

在 Eedi 数据集中，每道题只对应一个知识点，因此：

```text
forget(u, e) = forget(u, k_e)
```

其中 `k_e` 是题目 `e` 对应的唯一知识点。

## 3. 只出现一次的习题，forgetting rate 是多少？

只出现一次的习题，`forgetting rate` 不一定是 `0`。

需要区分以下几种情况：

| 情况 | forgetting rate |
|---|---|
| 学生刚刚做过该题对应知识点 | `Δt = 0`，遗忘率为 `0` |
| 学生曾经做过该题对应知识点，但之后又做了很多其他题 | `Δt > 0`，遗忘率大于 `0` |
| 学生没有做过这道题，但做过同知识点的其他题 | 根据该知识点最近一次出现时间计算，不一定为 `0` |
| 学生从未接触过该题对应知识点 | 当前设为 `0` |

因此：

> “只出现一次的题”不是直接设为 `0`。如果该题对应知识点曾经出现过，但距离当前状态已经过了一段时间，那么遗忘率会大于 `0`。

## 4. 没有出现过的习题，forgetting rate 是多少？

如果学生没有做过某道题，需要继续看该题对应的知识点是否出现过。

### 4.1 题目没做过，但知识点出现过

如果学生没有做过题目 `e`，但做过同一知识点下的其他题，那么：

```text
forget(u, e) = forget(u, k_e)
```

也就是说，该题的遗忘率仍然可以由对应知识点的历史接触情况推出来。

### 4.2 题目没做过，知识点也没出现过

如果学生从未接触过该题对应知识点，当前代码将遗忘值设为：

```text
forget(u, k) = 0
```

这并不是表示“学生完全没有遗忘”，而是表示：

> 没有历史接触记录，因此不存在可计算的时间遗忘过程。

从建模角度看，这是一个保守处理。它把“未学习过”和“刚刚学习过”都映射到了低遗忘值，这可能会带来一定噪声。后续如果进一步改进，可以额外加入 `seen_mask` 区分：

```text
未见过
```

和：

```text
见过但未遗忘
```

## 5. Eedi 数据集中学生做题情况

当前 Eedi 数据集统计如下：

| 统计项 | 数值 |
|---|---:|
| 学生数 | `935` |
| 习题数 | `948` |
| 知识点数 | `57` |
| 交互数 | `98,742` |
| 每个学生平均做题数 | `105.6` |
| 每个学生平均覆盖习题比例 | `11.0%` |
| 每道题全局平均被做次数 | `104.2` |
| 全局没人做过的题 | `29` |
| 全局只被做过 1 次的题 | `8` |
| 学生-题目交互对中只出现 1 次的比例 | `98.74%` |

因此，需要区分两个概念：

### 5.1 从全局看

Eedi 中并不是大量题目全局只出现一次。每道题平均被做约 `104` 次，全局只被做过一次的题只有 `8` 道。

### 5.2 从单个学生看

对单个学生而言，绝大多数学生-题目交互只出现一次。也就是说：

> 学生通常不会反复做同一道题。

这对遗忘建模非常重要。因为当前题目级遗忘并不是来自“同一道题多次作答后的遗忘轨迹”，而是主要来自“该题对应知识点最近一次出现时间”的间接估计。

## 6. Eedi 遗忘值分布

当前 Eedi 的遗忘值分布如下：

| 文件 / 范围 | median | mean | p90 | max | 0 值比例 |
|---|---:|---:|---:|---:|---:|
| `stu2know_forget.json` | `0.190` | `0.276` | `0.728` | `0.977` | `34.68%` |
| `stu2ex_forget.json` | `0.250` | `0.294` | `0.683` | `0.977` | `20.13%` |
| 已做过的学生-题目对 | `0.305` | `0.347` | `0.712` | `0.977` | `3.61%` |
| 没做过的学生-题目对 | `0.235` | `0.287` | `0.683` | `0.977` | `22.17%` |

可以看到，遗忘值不是全 0，也不是全 1，而是有一定分布。但没做过的学生-题目对中，0 值比例更高，这是因为有些题目对应的知识点对该学生而言从未出现过。

## 7. 为什么 `N >= 30` 时 No-Forgetting 更好？

图中 Eedi 的结果显示，当推荐列表长度较大时，例如 `N >= 30`，`No-Forgetting` 的 ACC 反而略高。这可以从以下几个角度解释。

### 7.1 题目级遗忘是由知识点遗忘间接得到的

Eedi 中每道题只对应一个知识点，因此题目遗忘值实际上等于该知识点遗忘值：

```text
forget(u, e) = forget(u, k_e)
```

这意味着，题目级遗忘并没有直接利用该学生对该题的多次作答轨迹，而是用知识点最近接触间隔进行估计。

当学生很少重复做同一道题时，这种估计会更偏向“知识点层面的粗粒度遗忘”，而不是“题目层面的精细遗忘”。

### 7.2 未做过题目很多，遗忘值包含间接估计

Eedi 中每个学生平均只做过约 `11%` 的题。也就是说，对一个学生来说，大部分候选题都是没有直接做过的。

对于这些未做过的题：

- 如果对应知识点出现过，遗忘值由该知识点历史推断；
- 如果对应知识点没出现过，遗忘值设为 `0`。

因此，遗忘关系中包含较多间接估计值。这些值对短列表可能有帮助，但当推荐列表变长时，噪声影响会被放大。

### 7.3 遗忘边非常密，长列表更容易受噪声影响

遗忘关系是学生-题目级别的关系，规模接近：

```text
学生数 × 题目数
```

对于 Eedi，大约是：

```text
935 × 948
```

这类边比掌握关系更密，也比学生真实做题记录更密。密集边可以提供更多信息，但也更容易把估计误差传播到图表示学习中。

在 `Top-5`、`Top-10` 这类短推荐列表中，遗忘关系可能帮助模型挑出更有复习价值的题。但在 `Top-30` 之后，候选范围扩大，遗忘边中的间接估计和噪声可能影响更多题目的排序，因此 `No-Forgetting` 可能表现更好。

### 7.4 No-Forgetting 更好不等于遗忘机制无效

`No-Forgetting` 在较大 `N` 上更好，并不说明遗忘因素本身没有意义，而是说明当前的遗忘建模方式仍然比较粗：

1. 它是由知识点最近接触间隔间接推到题目上的；
2. 它没有区分“从未学习过”和“刚学过但未遗忘”；
3. 它对未做过题目的遗忘估计较多；
4. 它生成的是非常密集的学生-题目边，可能在图训练中带来噪声。

因此，更准确的表述是：

> 当前遗忘关系在短推荐列表中可以提供复习需求信号，但在较长推荐列表中，由于题目级遗忘主要来自知识点层面的间接估计，且遗忘边较密，可能引入噪声。因此 Eedi 上出现 `N >= 30` 时 `No-Forgetting` 更好的现象。

## 8. 可以对老师这样回答

可以简洁表述为：

> 我们的 forgetting rate 不是根据题目出现次数直接设定的，而是先计算学生对知识点的遗忘程度，再映射到题目上。对于学生已经接触过的知识点，遗忘率由最近一次接触该知识点到当前状态的间隔通过指数衰减函数计算；对于从未接触过的知识点，目前设为 0，表示没有可计算的时间遗忘过程。Eedi 中并不是很多题目全局只出现一次，但对单个学生来说，绝大多数学生-题目交互只出现一次，学生很少重复做同一道题。因此，当前题目遗忘率主要是知识点层面的间接估计，而不是题目重复练习后的真实遗忘轨迹。当推荐列表较长时，这种密集的间接估计边可能引入噪声，所以在 `N >= 30` 时 `No-Forgetting` 结果反而略好。
