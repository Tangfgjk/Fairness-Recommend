## 本阶段完成

1. 新增 `Code/codes-New-ConvE/educational_kg_v2.py`，从现有正式 ER 图构建 KC 中心的 Schema v2 消息图。它保留原始数据集与原始推荐标签文件，不重写既有实验。
2. 消息边包括训练学生的 `mastery`、非零 `forgetting`，以及 Q 矩阵提供的 `covers`，每种边有逆向关系，认知数值作为连续边强度。测试学生的认知边不进入传播图。
3. **`rec` 边只作为原训练脚本中的监督标签，不进入消息传播。** 若在传播图中放入要预测的 `uid-rec-ex` 边，会发生标签泄漏。Schema v2 的推荐关系因此存在于任务定义中，但传播邻接不含它。
4. 新增 `Code/codes-New-ConvE/semantic_compgcn.py`。模型先使用原有语义实体编码，再做关系组合消息传播，并复用 ConvE 解码器与 KPPD 去偏头。`--backbone conve` 仍为默认，已有实验入口的默认行为不变。
5. `run_semantic_conve.py` 和 `test_semantic_conve.py` 已可选择 CompGCN；检查点记录传播图 SHA-256，推理时验证图未被替换。模型进入推理模式后缓存传播结果，避免每个候选习题重新传播全图。

## 生成和最小运行示例

在项目根目录运行：

```powershell
$graph = '.\Code\Data_Fin_New\algebra2005\forgetting_variants_rec50\drop_exfr0p00\er_graph'
python .\Code\codes-New-ConvE\educational_kg_v2.py --graph-dir $graph --output (Join-Path $graph 'educational_kg_v2.npz')
python .\Code\codes-New-ConvE\run_semantic_conve.py --data-path $graph --dataset-name algebra2005 --save-path .\Code\tmp\compgcn_example --backbone compgcn --compgcn-layers 1 --popularity-debias global_personal_need --tail-bias-mode pop_branch --epochs 1 --max-train-batches 1 --bs 4 --negative-ratio 1 --cuda false
python .\Code\codes-New-ConvE\test_semantic_conve.py --data-path $graph --dataset-name algebra2005 --save-path .\Code\tmp\compgcn_example --max-test-users 1 --score-mode debiased --cuda false
```

上述命令是**接口冒烟检查**，仅训练一个批次，不能作为论文指标或模型效果结论。正式运行需独立 run 目录、完整 epoch、统一种子、同一评价口径，并保存 ConvE 对照。
