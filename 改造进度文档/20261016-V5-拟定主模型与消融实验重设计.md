# V5 拟定主系统与消融实验重设计

日期：2026-10-16。状态：**实验设计，尚非效果结论**。对应分支：`V5-20261016`。

## 1. 拟定主系统

拟定完整系统为 **语义特征表示 → CompGCN 图传播 → ConvE 打分器 → KPPD 去偏打分 → Post 重排**，并在训练前使用 Pre(item+KC) 调整推荐边。对应当前配置名 `pre_in_kppd_post` 加 `--backbone compgcn`。这里的 CompGCN 是加在原有 ConvE 打分器**前面的图编码层**，并不取代 ConvE：`SemanticCompGCN` 继承原 `TwoCKG4ER`，更新实体/关系表示后仍调用原 `conve_transform`。Pre 改训练推荐边；KPPD 是训练中去偏与推理打分；Post 是分数输出后的重排。论文中宜称“完整方法/完整推荐系统”，不要把四阶段都称为 CompGCN 模型内部结构。

这一选择有方法上的合理性：CompGCN 在多关系图上组合实体与关系表示；本项目用它结合学生、知识点、习题的教育关系，再依次处理训练候选分布、流行度干扰和最终曝光。但能否确定为最终主系统，必须看完整三种子实验是否在三数据集上给出可接受的推荐质量与公平性权衡。官方 CompGCN 论文及代码验证的是通用知识图谱表示能力，并不证明这四阶段组合在本任务上必然更好。

当前固定数据为 Eedi 新划分、Algebra2005 和 XES 原划分，均采用 `(θ_m,θ_f,rec)=(0.8,0.8,50)`、删除零习题遗忘边。所有组使用同一数据划分、2024/2025/2026 种子、Top-N=5,10,…,50、训练预算和评价口径。比较阶段效果时只切换一个阶段；评价始终覆盖完整测试学生。

## 2. 主消融：Pre/In/Post 的完整 2×2×2 设计

以下八组均固定 **CompGCN**。`P` 是 item+KC 预处理，`I` 是 KPPD，`O` 是 quota_ratio_hybrid 重排。`0` 表示不启用该阶段，`1` 表示启用。

| P/I/O | 实验名 | 作用 | 当前代码 |
| --- | --- | --- | --- |
| 0/0/0 | `baseline` | CompGCN 基线 | 已有 |
| 1/0/0 | `pre_item_kc` | 仅 Pre | 已有 |
| 0/1/0 | `in_kppd` | 仅 In | 已有 |
| 0/0/1 | `post_only` | 仅 Post，在 baseline 分数上重排 | 已有 |
| 1/1/0 | `pre_in_kppd` | **完整系统去掉 Post** | 已实现 |
| 1/0/1 | `pre_item_kc_post` | **完整系统去掉 KPPD** | 已实现 |
| 0/1/1 | `in_kppd_post` | **完整系统去掉 Pre** | 已有 |
| 1/1/1 | `pre_in_kppd_post` | 拟定完整系统 | 已有 |

其中最重要的三个配对差值为：`111−011`（Pre 的增量）、`111−101`（KPPD 的增量）、`111−110`（Post 的增量）。单阶段组和 `000` 说明这些阶段各自及组合后的趋势；它们不能替代上述三个配对。KPPD 当前作为一个完整阶段移除时，会同时关闭对应训练目标、流行度分支及去偏打分，因此“去 KPPD”结论只针对这个整套 In 模块。

Post 只对分数重排。相同数据集、种子、P/I 设置下，`001` 复用 `000` 的分数，`101` 复用 `100`，`011` 复用 `010`，`111` 复用 `110`；再分别评价重排前后。编排器已实现四组复用；每数据集每种子训练四种 P/I 配置，随后产生八组评价。Post 组状态文件会记录来源实验与分数文件。

## 3. 图编码层消融：有无 CompGCN

第九组在 `111` 下比较 **语义特征 → CompGCN → ConvE** 和 **语义特征 → ConvE**，其余 Pre/KPPD/Post、数据和种子保持一致。这是“去掉 CompGCN 图编码层”的对照；两组都保留 ConvE 打分器。第九组使用独立批次目录；其中 `110` 是为生成 `111` 的分数而运行的内部父实验，不另计为第十组。后续可再比较 `000` 下的两种结构，区分图编码层单独增益与四阶段组合交互。参数量与训练时间应另列，避免只看质量指标。

两套结构使用不同批次目录，不能恢复或复用彼此的检查点。当前命令行把这一开关命名为 `--backbone conve|compgcn`：`conve` 表示直接使用原语义表示与 ConvE，`compgcn` 表示先图传播、再用**同一个 ConvE 打分器**。外部八个对比模型维持原训练和评价方式，不随此开关重复训练。

## 4. 第二层组件消融：先做少而明确的组

在主消融后，若 CompGCN 的增益值得继续解释，再于固定完整系统中测试：

1. **去连续边强度**：保留掌握/遗忘边及关系类型，将传播强度改成统一常量，检验连续数值编码是否有贡献。
2. **去掌握传播 / 去遗忘传播**：分别从 CompGCN 消息图删除对应关系及逆边；若只改消息图，名称必须写成“无掌握消息/无遗忘消息”，因为监督三元组和语义特征仍可能含这些信息。若要声称“完全去掌握/遗忘”，还必须同步重建监督关系、特征及推荐边，并保持所有对照口径可解释。
3. **KPPD 分支**：分别考察全局流行度、个人流行度、教学需求。现有模式是嵌套启用，不能仅靠当前参数实现所有单独删除组合；需要扩展配置并确认训练与去偏推理同时关闭对应分支。

一层与两层传播，以及 `corr/sub/mult` 算子属于**超参数敏感性分析**，建议单独列图表，避免和结构消融混淆。当前默认一层 `corr` 仅为可运行设置，两层可能更充分地传递学生—知识点—习题的两跳信息，需要实测。

## 5. 评价与选择规则

每数据集先列每个种子的结果，再按三种子汇报均值和标准差；完整系统与各配对组使用相同种子求差。推荐质量记录 Ada、正式 `KG4Ex-NOV-Set`、Ep；公平性至少记录习题/知识点曝光 Gini、覆盖率和长尾曝光占比。另记录训练耗时、显存峰值及推理耗时。应同时报告各项质量变化，不能只因为公平性升高就宣称完整系统整体更好。

确定“最终主系统”的条件：完整系统在多个数据集与种子下表现稳定，公平性改善具有清晰方向，同时 Ada/Ep 不出现无法接受的下降；若 Post 或其他阶段损伤过大，应按消融结果删减，而不是预设四阶段必须全部保留。三种子样本量较小，结果中的波动和个别数据集例外需要明确呈现。

## 6. 当前实现边界

- 统一入口默认运行上述八组 CompGCN 消融，并增加第九组无 CompGCN 对照；主方法为 `pre_in_kppd_post`。独立 V3 入口也默认使用 CompGCN。
- Post 组复用对应无 Post 组的检查点产出的分数，不再单独训练。无 CompGCN 对照与主模型使用不同批次目录，避免检查点混用。
- CompGCN 的掌握/遗忘消息消融、连续边强度消融尚无专用消息图或训练配置；旧七项语义消融入口是 ConvE 编排，不能直接代用。
- 拟定主系统虽已完成单批次流程验证，三数据集、三种子的完整训练与效果统计尚未开始，现阶段不要把它写成已证实的最优方案。
