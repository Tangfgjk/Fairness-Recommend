# V6 学生编码修复与受控去偏实验说明

日期：2026-10-22。分支：`V6-20261022`，基于 `V5-20261021`（`b9cfc37`）。

## 研究定位与已有问题

研究主线为“教育质量约束下的习题与知识点曝光去偏”。CompGCN 是表示增强候选，Pre/KPPD/Post 是去偏组件；不能将增加图传播等同于实现公平性，也不能将分数相减写成已识别的自然直接效应。

V5 的 Pre+In、seed 2024、Post 前保存分数显示：Algebra2005 的 CompGCN 给 144 位测试学生生成同一个有序 Top-5，只涉及 5 道题；ConvE 为 32 个不同列表、16 道题。Eedi 的对应数字为 78/16 与 218/39（234 位测试学生）。这证明个性化不足在 Post 前已存在。训练学生有消息边、测试学生只有自环是结构不一致的已确认事实；尚不能仅凭这些观察认定其是全部性能差异的唯一原因。

## 本次代码修改

### 1. 学生编码与 CompGCN

`semantic_compgcn.py` 新增 `compgcn_student_mode`：

- `direct`：默认。先用原 `TwoCKG4ER.entity_embedding` 计算初始表示，再传播图消息；最终用初始学生表示替换图传播后的学生表示。学生无论是否属于训练集，都经过相同的 ConvE 特征路径。习题、知识点继续使用 CompGCN 表示，关系与 ConvE 解码、KPPD 接口保持原有融合。
- `graph`：保留 V5 的全实体图编码，用于历史推理和受控对照。

训练学生仍可向知识点发送消息，测试学生及 `rec` 标签仍不进入消息图。该改动未增加测试学生边。直接学生编码不保证一定改善个性化；需要完整训练后用列表多样性和教育指标共同判断。

检查点记录 `compgcn_impl_version=3` 和学生模式。推理读取旧 v2 检查点时自动选择 `graph`，不会悄悄按新模式解释旧权重。续训拒绝不一致的学生模式、图摘要、传播设置和已记录的训练目标等关键配置。纯 ConvE 使用 `--backbone conve`，不以“零层 CompGCN”冒充纯 ConvE。

### 2. 正式 Post 入口

`run_v3_kppd_pipeline.py` 与统一入口支持 `--rerank-method`，新默认 `quality_swap`。对应评分文件为 `2CKG4ER_uid_ex_scores_quality_swap.pkl`，评价目录为 `eval_quality_swap`，状态记录真实方法名。旧的 quota/soft 方法仍可显式指定。

默认采用 V5 独立复算的 `swap_guarded` 参数：

| 参数 | 值 |
|---|---:|
| lambda_item / lambda_kc | 0.20 / 0.10 |
| beta_item / beta_kc | 0.05 / 0.02 |
| swap_fraction | 0.10 |
| swap_score_margin / swap_need_margin | 0.03 / 0.03 |
| swap_candidate_ratio / swap_min_candidate_rank | 2.0 / 20 |

该方法控制模型分数与归一化教育距离代理的局部损失。它不保证正式 Ada 或 Ep 的下界；不能宣称已经实现 `Ep >= baseline - epsilon`。这是待验证的候选配置，不能将此前测试集探索直接写成独立验证后的最优参数。正式参数选择应使用独立验证学生，并冻结后再做最终测试。

### 3. KPPD 清理和对照

删除 `need - need.detach()` 的恒零损失。`need` 保持固定教育相关性先验，仍参与打分。保留 `need_aux=0` 日志字段及只接受 0 的旧 CLI 参数，避免误解旧配置。V5 的该权重本来为 0，因此这项清理本身不改变历史训练目标。

新增可单独运行的实验：

| 实验键 | 训练及打分设置 | 用途 |
|---|---|---|
| baseline | BCE、legacy tail bias、无流行度头 | 原模型参考 |
| bpr_only | BCE+BPR、mixed 采样、距离加权、legacy tail bias、无流行度头 | 检查排序训练组合的贡献 |
| bpr_matched | 同上，但使用与 KPPD 一致的 pop_branch tail bias、无流行度头 | 排除 tail bias 差异 |
| in_kppd | BCE+BPR、pop_branch、流行度分解、core 去相关 | 完整 In 组合 |
| in_kppd_no_decorr | 与 in_kppd 相同，去相关权重为 0 | 检查去相关约束的贡献 |

`bpr_only` 同时包含 BPR、采样与配对设置，不应将其效果单独归因于 BPR 公式。关系损失加权在本轮默认实验中仍为 `none`。辅助损失仅对启用的流行度分支计算，避免未启用分支的常数误差影响总损失记录。

`--kppd-mode global/global_personal/global_personal_need` 可用于进一步分支消融。默认 global/personal 减项系数为 1，去偏 logit 化简为 `core + beta_need * need`；这不代表 core 已无流行度信息。个人流行度画像属于描述性特征，不等于已识别的从众效应。

另复现并修复了去相关惩罚的数值问题：对常数 core 向量，原公式损失为 0 但梯度为 NaN。将方差乘积的下界限制移到平方根之前，常数 core 或常数流行度均得到有限梯度。正常非退化输入的公式保持相同。这项修复不证明历史实验发生过 NaN，也不能据此解释全部性能差异。

### 4. 个性化与回归诊断

新增 `audit_recommendation_personalization.py`。对每位学生的完整候选集计算分数与 `log1p` 训练流行度的 Pearson 相关，记录 Top-N 不同列表数、不同习题数、最大相同列表占比和不同分数数量。常数向量相关性输出 null，不伪装成零相关。支持参考分数文件，检查相同学生与候选维度后计算列表重合率及完全一致比例。

新推理可额外保存 `core` logits；V6 入口自动保存 KPPD 分量并运行诊断。相关性仅为描述证据，尚不包含条件于教育相关性/难度/KC 的公平性分析，也不替代 Ada、NOV 和 Ep。

### 5. 结果隔离与续跑

V6 使用新批次，旧 V5 一键脚本显式固定 `graph + quota_ratio_hybrid` 及旧奖励系数。批次配置核验允许追加实验阶段、数据集、随机种子，但拒绝复用已改变的模型、Post 或关键参数；子阶段还核对命令。根路径转为绝对路径后传给子进程，防止工作目录不同造成产物错位。

## V6 运行入口与实验数量

入口：`Code/codes-New-ConvE/run_v6_controlled_experiments.py`。默认 seed 2024、25 epochs、batch size 1024、learning rate 0.001、negative ratio 5、CompGCN corr/1 层/dropout 0.1。默认只跑 `controls`，顺序为 Eedi、Algebra2005、XES。

| phase | 内容 |
|---|---|
| controls | 纯 ConvE baseline；原 graph 学生 CompGCN baseline；direct 学生的 baseline、bpr_only、bpr_matched、in_kppd、in_kppd_no_decorr。每数据集 7 个训练/评价组 |
| main | direct 骨干的 8 个 Pre/In/Post 组合，加 ConvE 的 Pre+In+Post；Post 复用父模型分数，ConvE 的 Pre+In 父组也会自动生成 |
| all | 先 controls 再 main；已完成且配置相同的父组复用。每数据集总共 15 个不同评价组，其中 10 个需训练、5 个仅 Post。包含九组主消融及额外对照/父组 |

三个数据集 phase all 合计 45 个评价组、30 个训练组、15 个仅 Post 组；可显式增加 `--include-comparisons`，默认每数据集再跑 EB-CF、SB-CF、CBF、TransE、TransE-adv 五个对比模型，共 15 组。其他三个 KGE 对比模型可通过 `--comparison-models` 指定。

输出：`Code/runs/<dataset>/<dataset>_V6_2024_c`（ConvE）、`..._g`（graph 学生参考）、`..._d`（direct 学生候选）；各批次有 `V3_main_metrics_all.csv`、`V3_main_fairness_all.csv` 汇总，各组有 `personalization_audit.json`。对比模型使用 `<dataset>_V6_2024_comparison`。这些是新实验目录，现有 V5 论文表格不自动改写。

```powershell
$repo = 'C:\Users\21709\Desktop\Fairness-Recommend\Fairness-Recommend'
$py = 'C:\Users\21709\.conda\envs\rtx5060\python.exe'
Set-Location -LiteralPath $repo

# 仅检查计划，不启动训练、不创建结果目录。
& $py .\Code\codes-New-ConvE\run_v6_controlled_experiments.py --phase all --include-comparisons --plan

# 建议先完成 controls；续跑使用同一配置。
& $py -u .\Code\codes-New-ConvE\run_v6_controlled_experiments.py --phase controls --resume

# 再运行主消融与五个对比模型；或者只运行 --phase main。
& $py -u .\Code\codes-New-ConvE\run_v6_controlled_experiments.py --phase main --include-comparisons --resume
```

更换层数、组合算子或 KPPD 模式时必须换批次，例如 `--batch-id V6_corr2 --compgcn-layers 2`。改随机种子可用 `--seeds 2024,2025,2026`。在受控结果支持升级之前，不建议直接开展所有结构参数的组合搜索。

## 本轮验证及尚未完成的研究

验证覆盖学生直接编码/图编码区别、学生与图分支梯度、三元组与矩阵评分一致性、v2/v3 配置解释、Post 参数及路径、BPR/去相关对照、配置不匹配拒绝复用、列表坍缩诊断，以及三数据集运行计划。

本轮 68 项相关单元测试通过。Algebra2005 的 baseline、bpr_matched、in_kppd、post_only、pre_in_kppd、pre_in_kppd_post 共 6 个评价组完成真实数据链路检查，均覆盖全部 144 位测试学生；汇总 CSV 包含这 6 组，core 分量导出与诊断存在。相同参数续跑成功跳过已完成步骤。

从 V5 复制检查点到临时目录后，对 2 位学生完成旧版 graph 模式推理兼容检查，Top-5 与保存结果一致；跨设备复算分数最大绝对差约 0.000168，不能据此宣称逐值完全等价。临时检查没有改写 V5 的检查点或推荐文件。

真实数据采用独立冒烟批次：每个训练组仅 1 epoch、最多 1 个批次，评价全体 Algebra2005 测试学生，Top-5、Ep threshold 0.5。该测试只检查代码链路，不能用于报告 V6 模型性能或宣称学生表示问题已解决。完整训练、原仓库 ConvE 复现偏差定量比较、独立验证集选参、多种子稳定性和条件曝光偏差分析仍需后续实验。

层数/算子已可配置；连续边强度开关、学习残差和推断时接入测试学生历史边本轮未加入。优先完成直接学生路径的受控验证，再决定是否需要这些结构扩展。
