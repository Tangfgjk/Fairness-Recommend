# V5 九组消融与五个对比模型：2024 种子一键运行

日期：2026-10-16。运行入口：`Code/codes-New-ConvE/run_v5_nine_groups_seed2024.py`。

## 固定实验设置

- 数据集：Eedi 新划分、Algebra2005 原划分、XES3G5M-sub-small 原划分；均选用 `(θ_m, θ_f, rec)=(0.8, 0.8, 50)` 且删除零习题遗忘边的正式图。
- 随机种子仅 `2024`；主模型是 Pre(item+KC) + CompGCN 图编码 + ConvE 打分 + KPPD + Post 重排。
- 消融为八个 Pre/In/Post 组合和第九个无 CompGCN 图编码对照；第九组仍使用 ConvE 打分器。四个带 Post 的组复用对应无 Post 组的分数。
- 对比模型仅 `EB-CF,SB-CF,CBF,TransE,TransE-adv`，按此顺序交给对比实验入口。
- 全训练默认 `epochs=25`、`max_train_batches=0`，完整测试集评价 `max_test_users=0`；Top-N 为 `5,10,…,50`。本轮关闭额外的 E0 诊断。此处不使用冒烟检查的单批次限制。
- 所有数据集的九组消融全部结束后，才开始三个数据集的对比实验；任一阶段失败即停止。重跑相同命令会跳过已完成阶段，并对未完成阶段续跑。
- 默认批次名为 `V5_2024`。Eedi 的嵌套特征文件路径较长；入口会在运行前检查 Windows 派生图路径，过长时要求缩短 `--batch-id`，避免复制到一半失败。

## Windows PowerShell 命令

先核对计划；此命令只读取数据并打印计划，不创建运行结果：

```powershell
$repo = 'C:\Users\21709\Desktop\Fairness-Recommend\Fairness-Recommend'
$py = 'C:\Users\21709\.conda\envs\rtx5060\python.exe'
Set-Location -LiteralPath $repo
& $py .\Code\codes-New-ConvE\run_v5_nine_groups_seed2024.py --plan
if ($LASTEXITCODE -ne 0) { throw '运行计划或正式数据检查失败' }
```

开始完整训练；断点续跑也使用同一条命令：

```powershell
$repo = 'C:\Users\21709\Desktop\Fairness-Recommend\Fairness-Recommend'
$py = 'C:\Users\21709\.conda\envs\rtx5060\python.exe'
Set-Location -LiteralPath $repo
& $py -u .\Code\codes-New-ConvE\run_v5_nine_groups_seed2024.py
if ($LASTEXITCODE -ne 0) { throw 'V5 实验失败，请查看阶段日志后续跑' }
```

如需为新一轮完整实验使用不同批次目录，传入 `--batch-id <新名称>`，计划与正式运行保持同一名称。
