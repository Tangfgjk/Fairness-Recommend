### 2.2 当前代码不公平性定位

时间：公平性指标实现前

在改模型之前，我们先从数据和推荐输出角度分析不公平性来源。当前主模型虽然能够输出个性化习题分数，但原始评估只关注 `Ada` 和 `NOV`，没有衡量推荐资源是否被少数习题或少数知识点垄断。

定位出的主要不公平性包括：

1. 习题曝光不均：少量热门习题反复进入大量学生的推荐列表。
2. 知识点曝光不均：推荐知识点集中在少数高频知识点上。
3. 长尾资源缺失：训练集中低频习题和低频知识点很难进入 Top-K。
4. 覆盖率不足：即使推荐列表数量很大，实际覆盖到的习题和知识点仍然有限。

这说明第一阶段不应直接修改模型，而应先补齐公平性评估体系，确认 baseline 的问题规模。

### 2.3 文献阅读与指标设计

时间：2026-08-11 15:32 左右

根据 `E:\Fairness-aware\2CKG4ER\参考论文` 中的论文，结合公平推荐和教育推荐场景，确定第一阶段采用资源侧公平指标。主要理论依据包括：

| 文献方向 | 对本项目的启发 |
| --- | --- |
| Fairness of Exposure in Rankings | 推荐排序分配的是曝光机会，Top-K 排名会放大资源曝光差异 |
| FairMatch | Gini、Coverage、Long-tail 分析适合衡量推荐资源分布不均 |
| Equality of Learning Opportunity | 教育推荐不只要优化个体适配，还要关注学习机会是否均衡 |
| Fairness-Aware Explainable Recommendation over Knowledge Graphs | 公平性可以与知识图谱和可解释推荐结合，不必牺牲解释性 |
| 公平推荐综述类论文 | 后处理、预处理、模型内约束是公平性推荐常见改造路线 |

据此确定第一阶段主指标：

| 指标 | 含义 |
| --- | --- |
| `ItemExposureGini@K` | 习题曝光分布不均程度，越低越均衡 |
| `KCExposureGini@K` | 知识点曝光分布不均程度，越低越均衡 |
| `ItemCoverage@K` | Top-K 推荐覆盖到的习题比例，越高越好 |
| `KCCoverage@K` | Top-K 推荐覆盖到的知识点比例，越高越好 |
| `LongTailItemExposureShare@K` | 长尾习题获得的曝光占比，越高说明长尾习题机会更多 |
| `LongTailKCExposureShare@K` | 长尾知识点获得的曝光占比，越高说明知识点机会更均衡 |
| `HeadItemExposureShare@K` | 头部习题曝光占比，用于诊断热门习题垄断 |
| `HeadKCExposureShare@K` | 头部知识点曝光占比，用于诊断热门知识点垄断 |

这里的 K 是推荐列表长度。当前代码默认评估 `5, 10, 15, ..., 100`，但汇报和论文分析重点使用 `K=10,20,50,100`，这样更容易展示短列表和长列表下的变化趋势。

### 2.4 公平性指标接入代码

时间：2026-08-11 15:55 左右

本阶段新增并修改了以下核心文件：

| 文件 | 作用 |
| --- | --- |
| `fairness_metrics.py` | 新增公平性指标计算模块 |
| `evaluate_recommendations.py` | 在原有评估中接入公平性指标 |
| `summarize_semantic_results.py` | 汇总实验时支持公平性指标 |
| `test_fairness_metrics.py` | 为公平性指标补充单元测试 |

实现细节：

1. 从 `uid_ex_scores` 得到每个学生的 Top-K 习题推荐列表。
2. 从 `Q.txt` 建立 `exercise_to_kc` 映射。
3. 从训练集 `triples.txt` 统计 `item_popularity`。
4. 根据习题流行度推导 `kc_popularity`。
5. 基于训练集流行度划分 head 和 long-tail。
6. 计算习题曝光、知识点曝光、Gini、覆盖率和长尾曝光占比。

其中知识点曝光使用 fractional credit：一道题如果关联多个知识点，则该题一次曝光按 `1 / 知识点数` 分摊给各个知识点，避免多知识点习题被重复放大。

同时删除了 `Ep_sim`。原因是原实现带有固定模拟参数，不能真实表示学生做题前后掌握度变化，论文解释风险较高。删除后，第一阶段保留 `Ada`、`NOV` 和新增公平性指标。

| `quota_ratio_15pct` | 多前缀比例硬约束，长尾习题 15%，知识点覆盖 25% |
| `quota_ratio_hybrid` | 先满足比例硬约束，再用软约束分数继续排序 |

方法设计思路：

1. 后处理方法不重新训练模型，直接读取 baseline 的 `uid_ex_scores.pkl`。
2. 先构造候选池，再从候选池中重排 Top-K。
3. 软约束方法通过 `lambda_item`、`lambda_kc` 奖励长尾习题和新知识点覆盖，通过 `beta_item`、`beta_kc` 惩罚已高曝光资源。
4. 硬约束方法要求多个前缀，如 Top-10、Top-20、Top-50、Top-100，都达到指定长尾习题比例和知识点覆盖目标。
5. hybrid 方法把两者结合，先保证最低公平约束，再用软约束继续优化公平性。

## 4. 方法效果分析

### 4.1 baseline 证明了公平性改造必要性

baseline 在 `Ada` 和 `NOV` 上表现稳定，但公平性指标暴露出强烈集中：

- Top-10 长尾习题曝光为 0。
- Top-10 习题覆盖率只有 1.69%。
- Top-10 知识点覆盖率只有 10.53%。
- Top-50 长尾习题曝光仍然为 0。

这说明原始 2CKG4ER 虽然具备可解释推荐能力，但推荐机会在习题和知识点空间中分布不均，容易形成热门资源偏置。

### 4.2 软约束重排能显著提升整体公平性

`stronger_item` 和 `stronger_kc` 证明，使用软约束评分可以显著提高覆盖率、降低知识点曝光 Gini，并增加长尾知识点曝光。

其中 `stronger_item` 在 K=50 下：

- ItemCoverage 从 0.071730 提升到 0.143460。
- KCCoverage 从 0.228070 提升到 0.578947。
- LongTailKCShare 从 0.158974 提升到 0.558632。
- Ada 从 0.717112 降到 0.705409。

这说明软约束方法公平性提升强，但推荐质量会有更明显下降。

### 4.3 比例硬约束更适合解释和控制

`quota_ratio_10pct` 和 `quota_ratio_15pct` 的优势是约束清晰，便于论文表达：

- Top-10、Top-20、Top-50、Top-100 同时约束。
- 明确要求长尾习题占比达到一定下限。
- 知识点覆盖目标也有清楚比例。
- 所有用户的约束满足率均为 1.0。

相比软约束，比例硬约束的公平性提升较温和，但 Ada 损失更小，更适合做可控公平性增强和参数敏感性实验。

### 4.4 hybrid 是当前最有潜力的主方法

`quota_ratio_hybrid` 结合了硬约束和软约束：

1. 先保证多前缀比例下限，提供清晰的公平性解释。
2. 再用软约束继续选择长尾习题、新知识点、低曝光资源。
3. 在公平性提升上接近 `stronger_item`，但比纯软约束多了明确的约束解释。

因此，当前推荐将 `quota_ratio_hybrid` 作为后续论文主方法候选，将 `quota_ratio_10pct`、`quota_ratio_15pct` 和 `stronger_item` 作为对照或消融。

## 6. 当前阶段局限

本阶段结果还不能直接作为最终论文结论，需要注意以下限制：

1. 当前主要实验只跑了 Eedi 的 seed2024，尚未做多随机种子统计。
2. 当前公平性主体是习题和知识点资源，不涉及学生敏感属性公平。
3. 长尾定义基于训练集出现频次，只能表示历史曝光或交互稀疏，不等价于真实教育价值。
4. 当前重排是后处理方法，不改变 2CKG4ER 的训练目标，也没有让模型在训练过程中显式学习公平性。
5. 当前知识点公平基于 `Q.txt` 映射，后续如果引入更完整知识图谱，需要重新定义路径级或关系级公平指标。

## 7. 后续工作建议

第一阶段可以暂时收束。下一阶段建议按照以下顺序推进：

1. 多 seed 复现实验：先在 Eedi 上跑 `2024,2025,2026`，确认当前结论是否稳定。
2. 多数据集验证：扩展到 Assist2009、XES3G5M 等数据集。
3. 固定主方法候选：优先保留 `quota_ratio_hybrid`，同时保留 `quota_ratio_10pct`、`quota_ratio_15pct` 和 `stronger_item` 作为对照。
4. 做参数敏感性：测试不同长尾比例、知识点覆盖比例、候选池大小。
5. 再考虑模型内公平性改造：例如在训练损失中加入曝光正则、知识点覆盖约束，或替换 ConvE 为更新的图推荐模型。
6. 考虑知识图谱增强：将习题、知识点、技能层级、学生掌握状态纳入更完整的 KG 推荐与解释路径分析。

## 8. 可用于汇报的一句话结论

第一阶段我们完成了从原始 2CKG4ER 到公平性推荐研究基线的搭建：先通过文献确定习题和知识点资源侧公平指标，再将这些指标接入评估流程，并在 Eedi seed2024 上证明原模型存在明显热门习题和知识点曝光集中问题；进一步通过后处理重排验证了公平性改造的可行性，其中 `quota_ratio_hybrid` 在保持可解释硬约束的同时显著提升习题覆盖、知识点覆盖和长尾曝光，是后续论文主方法的优先候选。
