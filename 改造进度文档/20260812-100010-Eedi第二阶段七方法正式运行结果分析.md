## 3. 方法级分析

### 3.1 baseline

baseline 与第一阶段判断一致：Ada 和 NOV 稳定，但公平性仍有明显集中。

例如：

- K=50 时 `KCCoverage=0.228070`，`LongTailItemExposureShare=0.000000`。
- K=100 时 `ItemCoverage=0.129747`，`KCCoverage=0.438596`。

说明原模型仍倾向于少数习题和少数知识点。

### 3.2 fairkg_edges

只加入 `ex_has_kc/kc_has_ex` 边后，效果比较混合。

正向现象：

- K=50 时 Ada 略升 `+0.000838`，NOV 略升 `+0.000105`。
- 长尾 KC 曝光在 K=50 和 K=100 都有提升。

负向现象：

- K=100 的 `KCCoverage` 从 `0.438596` 降到 `0.368421`。
- ItemCoverage 在多个 K 上下降。

结论：只补 KG 边不足以稳定提升公平性。它可以作为“知识结构补全”的基础消融，但不宜单独作为主方法。

### 3.3 fairkg_weighted

fairkg_weighted 在 fair KG 上加入关系 loss 平衡。

正向现象：

- K=10 的 Ada 最高，为 `0.724607`。
- K=50 的 ItemCoverage 和 KCCoverage 略有提升。
- K=100 的 KC Gini 下降，LongTailKCShare 提升。

负向现象：

- 整体公平性提升仍然有限。
- 对长尾 item 曝光帮助不稳定。

结论：关系权重能缓解部分关系规模不均衡，但它更像稳定训练目标的辅助模块，不是主要公平性来源。

### 3.4 fairreg_item

fairreg_item 是本轮最稳定的模型内公平方法。

正向现象：

- K=50：ItemCoverage 从 `0.066456` 提高到 `0.075949`，KCCoverage 从 `0.228070` 提高到 `0.315789`。
- K=100：ItemCoverage 从 `0.129747` 提高到 `0.141350`，KCCoverage 从 `0.438596` 提高到 `0.526316`。
- Ada 基本不损失，K=100 甚至略高于 baseline。

结论：item 期望曝光正则是值得保留的模型内公平模块。它虽然叫 item 正则，但通过 Q 矩阵关联，也能带来 KC 覆盖提升。

### 3.5 fairreg_kc

fairreg_kc 对长尾 KC 曝光有帮助，但对覆盖率不稳定。

正向现象：

- K=50：LongTailKCShare 从 `0.158889` 提高到 `0.209316`。
- K=100：LongTailKCShare 从 `0.194530` 提高到 `0.235897`，KC Gini 从 `0.778961` 降到 `0.767646`。

负向现象：

- K=100 的 KCCoverage 下降到 `0.421053`。
- ItemCoverage 下降。

结论：KC 正则目前更像“调整 KC 曝光分布”，但不一定增加 KC 覆盖。后续需要调参数或改目标函数，否则单独作为主方法说服力不如 fairreg_item。

### 3.6 fairreg_item_kc

联合 item/KC 正则没有取得预期结果。

现象：

- K=50 Ada 最高，为 `0.719990`。
- 但 K=50 的 `KCGini` 变差，从 `0.848664` 升到 `0.873894`。
- K=50 的 `KCCoverage` 从 `0.228070` 降到 `0.192982`。
- K=100 的 LongTailItemShare 和 LongTailKCShare 都低于 baseline。

结论：当前 `alpha_item=0.05, alpha_kc=0.05` 的联合正则可能发生目标冲突，或者 KC 目标分布过于保守。不能直接把 `fairreg_item_kc` 作为最终模型内主方法，需要先做参数调优。

### 3.7 fairreg_item_kc_hybrid_rerank

hybrid 是本轮公平性提升最明显的方法。

K=50：

- Ada 从 `0.716768` 降到 `0.712478`，下降 `0.004290`。
- NOV 从 `0.980475` 升到 `0.981843`。
- KCGini 从 `0.848664` 降到 `0.727830`。
- KCCoverage 从 `0.228070` 提高到 `0.543860`。
- LongTailItemShare 从 `0.000000` 提高到 `0.100000`。
- LongTailKCShare 从 `0.158889` 提高到 `0.392821`。

K=100：

- Ada 下降 `0.003939`。
- KCGini 下降 `0.070117`。
- ItemCoverage 提高 `0.014768`。
- KCCoverage 提高 `0.105264`。
- LongTailItemShare 提高 `0.071966`。
- LongTailKCShare 提高 `0.110769`。

结论：hybrid 在可接受 Ada 损失下显著提升 KC 公平和长尾曝光，是当前第二阶段最强的公平性方法。但要注意，它的主要提升来自后处理重排，模型内 `fairreg_item_kc` 本身并没有充分证明有效。

## 4. 结论

当前结果支持以下判断：

1. **第二阶段代码已经完整跑通。**  
   七个方法全部完成，比较表已生成。

2. **只加 KG 边的收益有限。**  
   `fairkg_edges` 有少量长尾 KC 提升，但覆盖率不稳定。

3. **关系 loss 权重是辅助模块。**  
   `fairkg_weighted` 有局部收益，但不足以单独作为公平性主方法。

4. **`fairreg_item` 是最稳的模型内公平模块。**  
   它在不明显损失 Ada 的情况下提升 ItemCoverage 和 KCCoverage。

5. **`fairreg_kc` 需要调参。**  
   它能提升长尾 KC 曝光，但覆盖率不稳定。

6. **`fairreg_item_kc` 当前参数不理想。**  
   联合正则在 K=50 上提升 Ada，但公平性变差，说明 item/KC 正则存在冲突或权重设置不合理。

7. **`fairreg_item_kc_hybrid_rerank` 是当前公平性最优方案。**  
   它显著提升 KCCoverage、LongTailItemShare、LongTailKCShare，并明显降低 KCGini。

## 5. 论文实验建议

当前不建议直接把 `fairreg_item_kc` 作为最终主方法。更合理的论文叙述是：

1. baseline 证明原始 2CKG4ER 存在资源曝光不均。
2. KG 边补全提供知识点结构，但单独使用不够。
3. 模型内 item 期望曝光正则能稳定改善覆盖。
4. KC 正则和联合正则需要进一步参数敏感性分析。
5. 当前最有效方法是“模型内公平训练 + quota_ratio_hybrid 后处理”的组合版本。

建议保留的核心对比：

```text
baseline
fairkg_edges
fairkg_weighted
fairreg_item
fairreg_kc
fairreg_item_kc
fairreg_item_kc_hybrid_rerank
```

论文主表建议优先报告：

```text
K=10, K=50, K=100
```

其中 K=50 最能体现公平性收益和推荐质量 trade-off。

