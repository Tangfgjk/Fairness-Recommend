# 第二阶段公平性重排模块实现记录

## 1. 本次实现目标

本次新增离线后处理模块 `fairness_rerank.py`，用于在不修改基础模型 `2CKG4ER/ConvE`、不重新训练的前提下，对模型输出的 `uid_ex_scores.pkl` 进行公平性重排。

该模块不会影响正在运行的 baseline 训练、测试和统计流程。它只在 baseline 已经生成分数文件之后单独运行。

## 3. 重排输入与输出

输入：

- `--data-dir`：图数据目录，需要包含 `Q.txt` 和 `triples.txt`
- `--scores-file`：基础模型生成的 `2CKG4ER_uid_ex_scores.pkl`
- `--output-file`：重排后的分数文件

输出：

- 重排后的 `uid_ex_scores.pkl` 或 JSON
- 元数据文件，默认命名为 `输出文件名.pkl.metadata.json`

注意：重排后的分数是 rank-only scores，主要用于让现有 `evaluate_recommendations.py` 按新的推荐顺序取 Top-K。分数绝对值不再表示原模型预测强度。

## 4. 支持的重排方法

当前支持：

- `baseline`：不改变原始排序，主要用于调试。
- `item`：偏向低流行度习题，缓解热门习题过度曝光。
- `kc`：偏向补充当前用户推荐列表中尚未覆盖的知识点，同时考虑低流行度知识点。
- `item_kc`：同时考虑习题公平和知识点公平，作为第二阶段第一版主方法。

## 5. 当前重排打分思想

对每个学生，在原模型分数的候选池内逐步选择推荐习题。每个候选习题的重排分数由以下部分组成：

```text
rerank_score =
  normalized_original_score
  + lambda_item * item_tail_bonus
  + lambda_kc * kc_bonus
  - beta_item * item_exposure_penalty
  - beta_kc * kc_exposure_penalty
```

其中：

- `normalized_original_score`：原模型分数在候选池内 min-max 归一化后的相关性。
- `item_tail_bonus`：低流行度习题获得更高奖励。
- `kc_bonus`：低流行度知识点和当前用户列表中新覆盖知识点获得奖励。
- `item_exposure_penalty`：已经被推荐较多的习题受到惩罚。
- `kc_exposure_penalty`：已经被推荐较多的知识点受到惩罚。

## 7. 参数建议

第一轮建议先跑：

- `lambda-item=0.3`
- `lambda-kc=0.3`
- `beta-item=0.1`
- `beta-kc=0.1`
- `candidate-multiplier=3`
- `top-k=100`

如果公平性提升不明显，可以逐步提高 `lambda-item` 和 `lambda-kc`。

如果 `Ada` 或 `NOV` 下降明显，可以降低 `lambda-item`、`lambda-kc`，或提高候选池质量要求。

## 9. 后续实验顺序

建议 baseline 完成后按以下顺序比较：

1. `baseline`
2. `item`
3. `kc`
4. `item_kc`

先固定一组参数跑通，再做参数敏感性实验：

- `lambda-item = 0.1, 0.3, 0.5`
- `lambda-kc = 0.1, 0.3, 0.5`

核心观察目标：

- `ItemExposureGini@K` 是否下降。
- `KCExposureGini@K` 是否下降。
- `ItemCoverage@K`、`KCCoverage@K` 是否提升。
- 长尾习题/知识点曝光占比是否提升。
- `Ada@K`、`NOV@K` 损失是否可接受。
