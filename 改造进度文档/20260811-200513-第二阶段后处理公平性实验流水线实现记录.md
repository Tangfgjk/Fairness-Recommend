# 第二阶段后处理公平性实验流水线实现记录

生成时间：2026-08-11 20:05:13

## 1. 本次实现目标

本次实现的目标是把第二阶段的后处理公平性方法整理成可复现实验流水线，避免后续手工执行多条命令时出现参数遗漏、文件命名不一致、评估目录不统一等问题。

新增脚本：

`E:\Fairness-aware\2CKG4ER\Code\codes-New-ConvE\run_fairness_rerank_experiments.py`

新增测试：

`E:\Fairness-aware\2CKG4ER\Code\codes-New-ConvE\test_run_fairness_rerank_experiments.py`

该脚本串联三个步骤：

1. 调用 `fairness_rerank.py` 生成重排后的 `uid_ex_scores_*.pkl`。
2. 调用 `evaluate_recommendations.py` 生成对应 `eval_*` 目录。
3. 调用 `compare_fairness_results.py` 生成统一总表。

## 2. 默认方法

默认运行以下方法：

| 方法名 | 重排方法 | 输出分数文件后缀 | 评估目录 |
| --- | --- | --- | --- |
| `item_only` | `item` | `item_only` | `eval_item_only` |
| `kc_only` | `kc` | `kc_rerank` | `eval_kc_rerank` |
| `item_kc_rerank` | `item_kc` | `item_kc_rerank` | `eval_item_kc_rerank` |
| `stronger_item` | `item_kc` | `item_kc_stronger_item` | `eval_item_kc_stronger_item` |
| `stronger_kc` | `item_kc` | `stronger_kc` | `eval_stronger_kc` |
| `quota_ratio_10pct` | `quota_ratio` | `quota_ratio_10pct` | `eval_quota_ratio_10pct` |
| `quota_ratio_15pct` | `quota_ratio` | `quota_ratio_15pct` | `eval_quota_ratio_15pct` |
| `quota_ratio_hybrid` | `quota_ratio_hybrid` | `quota_ratio_hybrid` | `eval_quota_ratio_hybrid` |

同时保留可选方法：

| 方法名 | 作用 |
| --- | --- |
| `quota_mid` | 历史 Top-10 固定硬约束消融，可手动通过 `--methods quota_mid` 运行 |

## 3. 参数固化

脚本把当前已经验证过的参数固化为 preset，保证后续复现实验与当前结果一致。

示例：

| 方法 | 核心参数 |
| --- | --- |
| `item_only` | `lambda-item=0.8`, `beta-item=0.3` |
| `kc_only` | `lambda-kc=0.3`, `beta-kc=0.1` |
| `stronger_item` | `lambda-item=0.8`, `lambda-kc=0.3`, `beta-item=0.3`, `beta-kc=0.1` |
| `stronger_kc` | `lambda-item=0.3`, `lambda-kc=0.8`, `beta-item=0.1`, `beta-kc=0.3` |
| `quota_ratio_10pct` | `long-tail-item-ratio=0.1`, `kc-coverage-ratio=0.2` |
| `quota_ratio_15pct` | `long-tail-item-ratio=0.15`, `kc-coverage-ratio=0.25` |
| `quota_ratio_hybrid` | `long-tail-item-ratio=0.1`, `kc-coverage-ratio=0.2`, `lambda-item=0.8`, `lambda-kc=0.3`, `beta-item=0.3`, `beta-kc=0.1` |

默认公共参数：

| 参数 | 默认值 |
| --- | --- |
| `top-k` | `100` |
| `candidate-multiplier` | `1.5` |
| `min-candidates` | `150` |
| `top-ks` | `5,10,15,...,100` |
| `compare-ks` | `10,20,50,100` |
