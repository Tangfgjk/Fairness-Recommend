## 6. 贡献拆解

### 6.1 item_only 说明了什么

`item_only` 主要改善习题层面的公平：

- `ItemCoverage@10`：`16` -> `28`
- `ItemCoverage@50`：`68` -> `124`
- `ItemCoverage@100`：`125` -> `187`
- `ItemExposureGini@100`：`0.894325` -> `0.878763`

这说明习题覆盖和习题曝光均衡确实主要来自 item 项。

但 `item_only` 的 Top-10 长尾习题曝光几乎没有起来：

- `LongTailItemShare@10`：`0.000000` -> `0.000427`

说明单纯按 item 流行度奖励，还不足以稳定把长尾习题推入很短的 Top-10；需要与 KC 约束联动，或进一步引入 quota 约束。

### 6.2 stronger_kc 说明了什么

`stronger_kc` 主要改善知识点层面的公平：

- `KCExposureGini@10`：`0.940066` -> `0.818534`
- `KCCoverage@10`：`6KC` -> `22KC`
- `KCExposureGini@100`：`0.775163` -> `0.631673`

它是当前所有方法中 `KCExposureGini` 最低的方法，说明加大 KC 权重能显著缓解知识点曝光集中。

但它在习题覆盖上不如 `stronger_item` 或 `item_only`：

- `ItemCoverage@100`：`173`，低于 `stronger_item` 的 `188` 和 `item_only` 的 `187`
- `ItemExposureGini@100`：`0.889797`，弱于 `stronger_item` 的 `0.880464` 和 `item_only` 的 `0.878763`

### 6.3 stronger_item 仍是当前最均衡方案

`stronger_item` 在 K=10 的表现最好地兼顾了两个目标：

- 覆盖习题：`16` -> `29`
- 覆盖 KC：`6` -> `22`
- 长尾习题曝光：`0` -> `0.132906`
- 长尾 KC 曝光：`0.491026` -> `0.670085`

虽然 `stronger_kc` 的 `KCGini@10` 更低，但 `stronger_item` 在习题长尾曝光上更强，而我们的主线是“习题/知识点分布不均”，不能只优化 KC。

## 8. 论文实验建议

第二阶段第一版建议保留三类方法：

1. `item_only`
   - 作为习题公平项消融。
2. `kc_only`
   - 作为知识点公平项消融。
3. `stronger_item`
   - 作为当前主方法。

`stronger_kc` 可以作为参数敏感性或补充实验，说明 KC 权重增强后知识点公平更强，但综合习题公平不如 `stronger_item`。

## 9. 下一步

当前加权重排已经能证明后处理有效，但 `ItemExposureGini` 下降仍有限。下一步建议做 quota-based rerank：

- Top-10 至少包含一定比例长尾习题。
- Top-10 至少覆盖一定数量知识点。
- 满足约束后尽量保留原模型高分习题。

这样可以专门解决短列表中头部习题仍高度集中的问题。
