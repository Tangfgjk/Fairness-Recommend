## 1. V3 分支定位

V3 分支的核心任务不是继续把“习题/知识点公平”作为最终公平对象，而是将研究方向调整为：

> **面向学生学习机会的教育资源流行度去偏。**

当前阶段先不直接做学生侧学习机会公平结论，而是先证明推荐模型是否会放大训练数据中的热门资源偏差，并进一步验证预处理、模型内方法、后处理是否能缓解这种资源流行度偏差放大。

因此，V3 的主要目标可以概括为三件事：

1. 统一公平/去偏评价口径，避免继续使用 `triples.txt` 中的 `rec` 伪标签定义 popularity。
2. 建立偏差链诊断，从 `p_data -> p_label -> p_base -> p_debias` 证明偏差是否存在、是否被模型放大、去偏是否有效。
3. 在保留 ConvE/2CKG4ER 主干的基础上，完成一个换主干前的强去偏版本，即 KPPD-2CKG4ER。

## 2. 总体改造路线

V3 保留已有 Pre/In/Post 框架，但研究解释发生了调整：

| 模块 | V2/早期理解 | V3 重新定位 |
|---|---|---|
| Pre | 习题/KC 公平预处理 | 基于教育相关性的资源流行度去偏伪标签重构 |
| In | 模型中公平正则 | 模型内流行度 nuisance 建模与 debiased inference |
| Post | 公平重排 | 推荐结果层面的资源曝光去偏基线 |
| E0 | 辅助分析 | 核心偏差链诊断，用来证明偏差放大与缓解 |

V3 不再把 Item/KC Gini 直接表述为最终公平性，而是表述为：

```text
资源曝光集中度
热门资源偏差放大
长尾教育资源可见性
教育相关性约束下的资源分布改善
```

最终公平对象仍应回到学生，学生侧学习机会公平放到后续阶段验证。

## 6. Pre：公平预处理图构造

V3 对预处理模块进行了严格化，文件为：

```text
Code/codes-New-ConvE/fairness_preprocess_rec_graph.py
```

### 6.1 方法定义

预处理方法从原始教育距离出发：

```text
C_u = TopM_min_distance(u)
```

在每个学生的 Top-M 候选集合内计算教育相关性：

```text
R_ui =
1 - (d_ui - d_u,C_min) / (d_u,C_max - d_u,C_min + epsilon)
```

再加入 item 和 KC 的低流行度 prior：

```text
S_ui = R_ui + lambda_item * F_i_item + lambda_kc * F_i_KC
```

最终选：

```text
D_u_fair = TopK_{i in C_u} S_ui
```

其中：

- `lambda_item=0, lambda_kc=0` 时必须逐边复现原始 `rec` 图。
- `F_i_item` 来自真实训练交互或指定 popularity source。
- `F_i_KC` 由 Q-matrix 将 item popularity fractional propagation 到 KC 后再映射回 exercise。

### 6.2 实验验收增强

V3 最后几次提交主要强化了预处理模块的实验可信度：

- `lambda_item=0, lambda_kc=0` 时，如果不能重建原始 `rec` 边，直接 `RuntimeError`。
- `source_rec_edge_hash` 和 `output_rec_edge_hash` 统一 canonicalization 后再比较。
- `non_rec_relations_unchanged` 不再硬编码，而是写出后重新读取 `triples.txt` 验证。
- `rec_degree_preserved` 改为真正的逐用户 boolean 检查。
- 增加 `source_rec_degree`、`output_rec_degree`。
- 区分 `replaced_rec_edge_count` 和 `rec_edge_symmetric_difference_count`。
- 增加 `changed_user_count`、`changed_user_ratio`。
- 修正 promotion 指标，区分 `mean_promoted_original_rank` 和真正的 `mean_promotion_depth`。
- 输出图的 `er_graph_manifest.json` 会标注 `graph_variant=fairness_preprocessed`，原 manifest 保存为 `source_er_graph_manifest.json`。
- 已有非空输出目录默认报错，必须 `--force` 才允许重建，避免不同参数实验静默复用旧图。
- `candidate_pool_size` 在 manifest 中区分 requested/effective。
- 增加负 `lambda`、非法 `epsilon`、`top_k_rec<=0`、distance/Q shape mismatch、NaN/Inf 的 fail-fast 检查。

对应测试：

```text

```

测试覆盖包括：

- 零 lambda 精确重建。
- tie-breaking 与原始 ER graph generator 一致。
- Item prior 能提升低曝光候选。
- KC prior 能提升低曝光 KC 候选。
- non-rec 关系不变。
- graph manifest provenance 正确。

### 7.1 分数定义

V3 统一在 logit 空间定义 raw/debiased score：

```text
z_core(u, i)   ConvE core score
b_g(i)         global popularity component
b_p(u, i)      personal popularity component
n(u, i)        pedagogical guardrail component
```

raw logit：

```text
z_raw(u, i)
  = z_core(u, i)
    + beta_g * b_g(i)
    + beta_p * b_p(u, i)
    + beta_n * n(u, i)
```

debiased logit：

```text
z_deb(u, i)
  = z_raw(u, i)
    - lambda_g * beta_g * b_g(i)
    - lambda_p * beta_p * b_p(u, i)
```

这样避免了早期 `score - popularity + need` 表述不严谨的问题。

### 7.2 tail bias 模式

原 ConvE 中的：

```python
self.b[t]
```

可能成为隐藏的 item-ID/popularity shortcut。V3 新增：

```text
--tail-bias-mode legacy|none|pop_branch
```

| 模式 | 含义 |
|---|---|
| `legacy` | 保留原始 `self.b[t]`，用于复现旧 baseline |
| `none` | 移除 tail bias，检查 item shortcut 影响 |
| `pop_branch` | core 中不再使用 `self.b[t]`，流行度效应进入显式 popularity branch |

KPPD 主实验使用 `pop_branch`。

### 7.3 popularity debias head

新增参数：

```text
--popularity-debias none|global|global_personal|global_personal_need
```

其中：

- `global`：只建模全局资源流行度效应。
- `global_personal`：加入学生个体流行度偏好。
- `global_personal_need`：加入 pedagogical relevance guardrail。

全局流行度使用：

```text
standardized_log1p_train_popularity
```

个人画像包括：

```text
mean_pop_z
std_pop_z
head20_share
mid60_share
tail20_share
log_history_length
history_available
```

pedagogical guardrail 来自：

```text
stu2ex_recommend_full_precision.json
```

### 7.4 推理 score mode

推理支持：

```text
score_mode = raw|debiased
```

并支持导出 logit component：

```text
raw
debiased
global_pop
personal_pop
need
```

这使同一个 checkpoint 可以同时评价 raw 和 debiased，不需要重新训练。

## 14. 当前 V3 的边界与注意事项

V3 已经适合进入正式资源去偏实验，但仍有以下边界：

1. 当前不是最终学生侧公平实验，只是资源流行度去偏与偏差链诊断阶段。
2. 单 seed 结果用于筛选技术路线，不宜直接作为最终显著性结论。
3. KPPD 目前保留 ConvE 主干，尚未替换为 CompGCN。
4. D3 的 pedagogical guardrail 来自已有 full-precision educational distance，不是新训练的 KT 模型。
5. `rec` 边仍是构图伪标签，不应把方法过度表述为严格点击日志上的 counterfactual causal effect。
6. 旧 Pre/In/Post 框架仍保留，但 V3 主叙事应围绕 `p_data -> p_label -> p_raw -> p_debiased` 偏差链。
