# quota_ratio 比例公平性重排实现记录

## 1. 实现目标

本次在 `fairness_rerank.py` 中新增 `quota_ratio` 方法，用于把固定数量 quota 升级为多前缀比例 quota。

旧方法 `quota_strict` 只约束一个前缀，例如 Top-10：

```text
Top-10 至少 1 道长尾习题
Top-10 至少覆盖 10 个知识点
```

新方法 `quota_ratio` 可以同时约束多个前缀，例如：

```text
Top-10  至少 10% 长尾习题
Top-20  至少 10% 长尾习题
Top-50  至少 10% 长尾习题
Top-100 至少 10% 长尾习题
```

这样可以避免旧 quota 只在 Top-10 生效、到 Top-50/100 又退回 baseline 的问题。

## 3. 新增方法与参数

新增方法：

```powershell
--method quota_ratio
```

新增参数：

```powershell
--quota-prefixes
--long-tail-item-ratio
--kc-coverage-ratio
```

默认值：

```text
quota_prefixes = 10,20,50,100
long_tail_item_ratio = 0.1
kc_coverage_ratio = 0.2
```

## 4. 算法流程

对每个学生：

1. 从原始 2CKG4ER 分数中取候选池，例如原始 Top-150。
2. 根据训练集 `triples.txt` 中的习题流行度划分长尾习题。
3. 按 `quota_prefixes` 依次构造多个前缀。
4. 对每个前缀：
   - 计算长尾习题目标：`ceil(prefix * long_tail_item_ratio)`
   - 计算 KC 覆盖目标：`ceil(全局KC数 * kc_coverage_ratio)`
   - 先补足长尾习题比例。
   - 再补足知识点覆盖比例。
   - 剩余位置按原模型分数补齐。
5. 所有 quota 前缀处理完后，剩余 Top-K 位置按原模型分数补齐。

## 5. 可行性处理

如果候选池中无法满足某个 quota，代码会自动使用候选池内可达到的最大目标：

```text
有效长尾目标 = min(比例目标, 候选池长尾题数量, 当前前缀长度)
有效KC目标 = min(比例目标, 当前前缀可达到最大KC覆盖)
```

因此 `quota_ratio` 不会从候选池外强行拉入低相关习题。

## 6. metadata 输出

`quota_ratio` 会在 metadata 中输出：

```text
quota_satisfied_users
quota_satisfied_user_ratio
quota_prefix_summary
```

其中 `quota_prefix_summary` 会按前缀分别记录：

```text
average_long_tail_items
average_kc_coverage
average_effective_long_tail_target
average_effective_kc_target
satisfied_user_ratio
```

这可以直接检查 Top-10/20/50/100 是否都满足比例 quota。

## 8. 预期观察重点

与 `quota_mid` 相比：

1. `LongTailItemExposureShare@20/50/100` 应该不再快速衰减。
2. `ItemCoverage@50/100` 应该高于 `quota_mid`。
3. `Ada` 可能比 `quota_mid` 略低，但应低于过强 quota 的损失。
4. 如果 `quota_prefix_summary` 中每个前缀的 `satisfied_user_ratio` 都接近 `1.0`，说明候选池足够支持比例 quota。

与 `stronger_item` 相比：

1. 若公平提升接近但 Ada 更高，则 `quota_ratio` 可作为主方法候选。
2. 若公平提升弱但 Ada 高，则它适合作为保守强约束方法。
3. 若 Ada 损失大且公平不如 `stronger_item`，则应转向 `quota_hybrid`。
