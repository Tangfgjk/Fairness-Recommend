# KPPD-2CKG4ER 最终代码改进方案

日期：2026-09-20

## 1. 结论

本阶段继续保留当前 ConvE/2CKG4ER 主干，不立刻替换为 CompGCN。换主干前的最终改进目标是形成一个干净、可解释、可诊断的 ConvE-Debias 强基线：

> **KPPD-2CKG4ER：Knowledge-aware Personalized Popularity Debiased 2CKG4ER**

中文名称：

> **知识感知个体流行度去偏的 2CKG4ER 习题推荐模型**

最终模型应由四部分组成：

```text
ConvE Core
+ Ranking Objective
+ Popularity Nuisance Decomposition
+ Pedagogical Guardrail
```

其中，`Popularity Nuisance Decomposition` 用来显式拆出全局流行度效应和学生个体流行度偏好；`Pedagogical Guardrail` 用来保证去偏后仍保留教育适配性。

本方案采纳评阅意见中的核心修正：不再直接使用含混的 `s_main - popularity + need`，而是统一在 logit 空间定义 raw/debiased score；不再把方法正式命名为 counterfactual direct effect removal，而改为更严谨的 popularity-aware / popularity-subtracted inference。

## 3. 评阅意见采纳情况

| 意见 | 采纳情况 | 处理方式 |
|---|---|---|
| `self.b[t]` 是隐藏 item-ID shortcut | 直接采纳 | 新增 `--tail-bias-mode legacy|none|pop_branch`；Debias 模式默认 `pop_branch`。 |
| BCE 应统一到 logit space | 直接采纳 | 训练改为 `score_triples_logits` + `binary_cross_entropy_with_logits`。 |
| `s_main - pop + need` 定义不自洽 | 直接采纳 | 改为 `z_core / z_raw / z_deb` 三层定义。 |
| `rec` 标签不是点击日志 | 直接采纳 | 文档和方法名避免直接声称严格 causal direct effect。 |
| `global_pop` 不宜过复杂 | 采纳 | 第一版使用单调、可解释的标准化 log popularity 线性项。 |
| `personal_pop` 需要 history availability | 直接采纳 | profile 加入 `log_history_length` 和 `history_available`。 |
| need 分支不应自由 MLP | 直接采纳 | 改为 pedagogical distance guardrail。 |
| BPR 应利用教育距离 | 直接采纳 | BPR pair 只在距离差满足 margin 时构造，并支持 pair weight。 |
| hard negative 不能塞进 Dataset | 直接采纳 | `hard_mixed` 后置，单独设计 `HardNegativeMiner`。 |
| BPR 需要单独 `RecPairDataset` | 直接采纳 | BCE Dataset 与 BPR Pair Dataset 分离。 |
| `L_orth` 改成 `L_decorr` | 直接采纳 | 用相关性/协方差惩罚，不声称保证 disentanglement。 |
| Head/Mid/Tail 与 LongTail80 混淆 | 直接采纳 | 统一 bucket 命名，区分 `Head20/Mid60/Tail20` 与 `LongTail80`。 |
| E0 不应把 pop/need 当主链阶段 | 直接采纳 | 主偏差链保留 `p_data -> p_label -> p_raw -> p_debiased`，组件另做诊断。 |
| D4 不应重新训练 | 直接采纳 | D3 同一 checkpoint 同时输出 raw/debiased；D4 仅 inference 切分数。 |
| E2 主实验关闭旧 fairness regularizer | 直接采纳 | E2-D 系列全部 `--fairness-loss none`。 |
| metadata 旧版本残留 | 直接采纳 | E2 前清理 `gate_values.json`、`metrics.json`、模型版本号。 |
| runner 默认数据集过时 | 直接采纳 | 默认改为 `Eedi,algebra2005,XES3G5M-sub-small`。 |

## 4. 最终模型定义

### 4.1 分数组件

对学生 `u` 和习题 `i`，定义四个 logit component：

```text
z_core(u, i)   ConvE core score，不包含 item-ID tail bias
b_g(i)         global popularity score
b_p(u, i)      personal popularity score
n(u, i)        pedagogical need / relevance guardrail
```

推荐 raw logit：

```text
z_raw(u, i)
  = z_core(u, i)
    + beta_g * b_g(i)
    + beta_p * b_p(u, i)
    + beta_n * n(u, i)
```

推荐 debiased logit：

```text
z_deb(u, i)
  = z_raw(u, i)
    - lambda_g * beta_g * b_g(i)
    - lambda_p * beta_p * b_p(u, i)
```

当：

```text
lambda_g = lambda_p = 1
```

则：

```text
z_deb(u, i) = z_core(u, i) + beta_n * n(u, i)
```

解释为：去掉全局与个体流行度 nuisance，保留核心推荐和教育适配 guardrail。

### 4.2 tail bias 处理

当前 ConvE score 中存在：

```python
torch.sum(x * t_emb, dim=1) + self.b[t]
```

`self.b[t]` 是每个 entity 独立的 trainable scalar。对于习题推荐，它可能成为隐藏的 item-ID/popularity shortcut。

新增参数：

```text
--tail-bias-mode legacy|none|pop_branch
```

三种模式：

| 模式 | 行为 | 用途 |
|---|---|---|
| `legacy` | 保留当前 `self.b[t]` | 复现旧 baseline。 |
| `none` | 完全移除 tail bias | 检查 item-ID shortcut 的影响。 |
| `pop_branch` | core score 不含 `self.b[t]`，item popularity bias 进入 `b_g(i)` | KPPD 默认模式。 |

E2 主方法使用：

```text
--tail-bias-mode pop_branch
```

## 5. Global Popularity 分支

全局流行度输入使用真实训练交互：

```text
popularity_source = train_interactions
popularity_aggregation = unique_users
```

每个习题：

```text
p_i = standardize_train(log(1 + pop_item(i)))
```

全局流行度分数：

```text
b_g(i) = softplus(theta_g) * p_i + c_g
```

这样保证：

```text
popularity 越高，global popularity effect 单调不减
```

第一版不使用自由 MLP。原因是自由 MLP 只证明分支“知道 popularity”，不利于解释其作用。

辅助损失：

```text
L_global
```

用于约束 `b_g(i)` 与标准化 popularity 保持一致，重点是可解释和单调性，不把它写成严格因果效应估计。

## 6. Personal Popularity 分支

学生个体流行度画像：

```text
mean_pop
std_pop
head20_share
mid60_share
tail20_share
log_history_length
history_available
```

其中：

- `Head20/Mid60/Tail20` 用于 profile 和 E0 诊断。
- `LongTail80` 继续用于旧 long-tail resource visibility 指标。

测试学生 profile 必须只使用协议允许观察到的历史，不能直接泄漏未来交互。

对于没有可用历史的学生：

```text
history_available = 0
log_history_length = 0
profile 数值使用训练学生均值或 neutral bucket
```

个体流行度分数：

```text
b_p(u, i) = f(profile_u, p_i)
```

这里可以使用小 MLP，但必须记录输入 profile 和是否有历史。

辅助损失：

```text
L_personal
```

用于约束 `b_p(u, i)` 与学生历史流行度偏好一致。

## 7. Pedagogical Guardrail

need 分支不作为自由预测 MLP，而作为教育适配约束。

当前 `rec` 标签来自：

```text
d_ui = sqrt((delta_1 - mastery_product(u,i))^2
            + (delta_2 - forgetting(u,i))^2)
```

其中：

```text
delta_1 = 0.8
delta_2 = 0.8
```

因此本方案不使用简单的：

```text
max(0, target_mastery - mastery) + forgetting
```

作为主 need 分支。因为这会偏向“越不会越需要”，而原始推荐目标是接近适中掌握度和遗忘状态。

推荐使用：

```text
n(u, i) = normalized_relevance_from_distance(d_ui)
```

可选形式：

```text
n(u, i) = -standardize(d_ui)
```

或：

```text
n(u, i) = exp(-tau * d_ui)
```

其中 `d_ui` 来自 `stu2ex_recommend_full_precision.json`。

该分支命名为：

```text
pedagogical guardrail
```

不命名为自由 `need MLP`。它的作用是防止去热门以后推荐教育上不合适的长尾习题。

## 8. 训练目标

所有训练统一在 logit 空间进行。

总损失：

```text
L =
  L_BCEWithLogits
+ alpha_bpr * L_BPR
+ alpha_g * L_global
+ alpha_p * L_personal
+ alpha_n * L_need
+ alpha_d * L_decorr
```

其中：

- `L_BCEWithLogits` 作用于原三元组训练。
- `L_BPR` 只作用于 `rec` relation。
- `L_global` 约束全局流行度分支。
- `L_personal` 约束个体流行度偏好分支。
- `L_need` 约束 pedagogical relevance guardrail。
- `L_decorr` 减少 core score 与 popularity 的相关性。

不再使用：

```text
sigmoid(logit) -> binary_cross_entropy
```

改为：

```text
binary_cross_entropy_with_logits(logits, labels)
```

BPR：

```text
L_BPR = -log sigmoid(z_pos - z_neg)
```

同样使用 logit。

## 9. BPR Pair 与负采样

### 9.1 Dataset 分离

保留：

```text
TripleBCEDataset
```

负责原 KGE BCE 训练。

新增：

```text
RecPairDataset
```

输出：

```text
uid
pos_ex
neg_ex
pair_weight
```

训练时分别计算：

```text
L_BCE
L_BPR
```

再合并。

### 9.2 教育距离约束 BPR

不把所有非 Top-10 都当成等价 negative。使用 `stu2ex_recommend_full_precision.json` 中的教育距离：

```text
d(u, pos) + margin < d(u, neg)
```

才形成可信 BPR pair。

可选 pair 权重：

```text
pair_weight = f(d(u, neg) - d(u, pos))
```

距离差越大，pair 监督越可信。

### 9.3 negative sampling

第一阶段支持：

```text
random
popular
mixed
```

`mixed` 可以由以下组成：

```text
random negative
popular negative
near-boundary educational hard negative
```

`hard_mixed` 依赖当前模型分数，不能直接塞进 `Dataset.__getitem__()`。后续单独实现：

```text
HardNegativeMiner
```

每个 epoch 或每 N step：

```text
model.eval()
no_grad()
score candidates
refresh hard negative cache
```

## 10. Component Diagnostics 与 E0 偏差链

E0 主偏差链保持：

```text
p_data -> p_label -> p_raw -> p_debiased
```

解释：

- `p_data`：真实训练交互分布。
- `p_label`：由 mastery/forgetting 教育距离生成的 rec 伪标签分布。
- `p_raw`：模型 raw recommendation exposure。
- `p_debiased`：同一 checkpoint 下 debiased inference 的 exposure。

不把 `p_pop_effect` 和 `p_need` 硬塞进主链，因为它们是 score component，不是一个实际推荐分布生成阶段。

新增 component diagnostics：

```text
Corr(b_g, log_pop)
Corr(b_p, user_pop_profile)
Corr(n, pedagogical_relevance)
Corr(z_core, log_pop)
DeltaRank_remove_global_pop
DeltaRank_remove_personal_pop
Head20/Mid60/Tail20 rank movement
LongTail80 visibility change
```

其中：

```text
Corr(z_core, log_pop)
```

用于检查 core score 是否仍然偷学 popularity。

## 12. E2 实验设计

所有 E2 主实验关闭旧 fairness regularizer：

```text
--fairness-loss none
```

旧 `FairnessRegularizer` 作为 E1/in-processing baseline 保留，不混入 E2 主方法。

实验组：

| 编号 | 方法 | 训练 | 推理 |
|---|---|---|---|
| B0 | Legacy 2CKG4ER | BCE + legacy tail bias | raw |
| B1 | Clean Core 2CKG4ER | BCEWithLogits + tail bias none/pop_branch off | raw |
| N1 | Ranking 2CKG4ER | BCE+BPR + mixed negative | raw |
| D1-Raw | N1 + global popularity branch | 同 D1 checkpoint | raw |
| D1-Debias | N1 + global popularity branch | 同 D1 checkpoint | debiased |
| D2-Raw | D1 + personal popularity branch | 同 D2 checkpoint | raw |
| D2-Debias | D1 + personal popularity branch | 同 D2 checkpoint | debiased |
| D3-Raw | D2 + pedagogical guardrail | 同 D3 checkpoint | raw |
| D3-Debias | D2 + pedagogical guardrail | 同 D3 checkpoint | debiased |
| D4 | D3-Debias + post rerank | 不重新训练 | debiased + quota/soft rerank |

重点说明：

```text
D3-Raw -> D3-Debias
```

来自同一个 checkpoint，唯一变化是 inference 时是否 subtract popularity nuisance。因此该对比最能说明去偏推理本身的效果。

第一轮优先跑：

```text
B0
B1
N1
D1-Raw / D1-Debias
D2-Raw / D2-Debias
D3-Raw / D3-Debias
```

若 D3-Debias 稳定，再跑：

```text
D4
hard_mixed
CompGCN backbone
```

## 16. 实现顺序

建议按以下顺序实现：

1. 修复 logit training：`BCEWithLogits`、`score_triples_logits`、保持旧 baseline 可复现。
2. 增加 `tail-bias-mode`，处理 `self.b[t]` shortcut。
3. 清理 metadata 和 model version。
4. 实现 `RecPairDataset` 和教育距离约束 BPR。
5. 实现 `random/popular/mixed` negative sampler。
6. 实现 global popularity branch。
7. 实现 personal popularity profile 与 personal branch。
8. 实现 pedagogical guardrail。
9. 输出 raw/debiased/component logits。
10. 扩展 E0 偏差链和 component diagnostics。
11. 新增 E2 runner，默认三数据集单 seed。
12. 最后实现 hard negative miner。

这样做到 D3 时模型结构已经完整，D3-Debias 只需要切换 inference score，不需要重新训练。

## 17. 验收标准

代码层面：

1. `--popularity-debias none --tail-bias-mode legacy` 能复现旧模型行为。
2. BCE 训练全程使用 logits。
3. BPR 只作用于 `rec` relation。
4. D3 checkpoint 能同时输出 raw 和 debiased scores。
5. component logits 文件齐全。
6. E0 主链输出 `p_data/p_label/p_raw/p_debiased`。
7. component diagnostics 输出相关性与 rank movement。
8. E2 runner 默认只跑三个数据集和 seed 2024。

实验层面：

1. `D3-Debias` 相比 `D3-Raw`，ARP、Gini、JS 至少有一类资源侧偏差指标下降。
2. Ada/NOV 不发生明显崩坏。
3. `Corr(b_g, log_pop)` 为正且稳定。
4. `Corr(z_core, log_pop)` 低于 legacy baseline，说明 shortcut 被削弱。
5. 三数据集趋势不要求完全一致，但至少不能只在 Eedi 单点有效。

## 18. 术语约束

当前阶段推荐使用：

```text
popularity-aware bias decomposition
popularity-subtracted inference
personalized popularity debiasing
pedagogical guardrail
bias amplification mitigation
```

谨慎使用：

```text
counterfactual
direct effect removal
causal effect
unbiased recommendation
```

原因是当前 `rec` 标签并非真实点击日志，而是由 mastery/forgetting 教育距离生成的伪推荐标签。除非后续建立明确 SCM 和可识别假设，否则论文主方法不应声称严格因果去偏。

## 19. 与后续 CompGCN 的关系

KPPD 模块应尽量与主干解耦。未来替换为 CompGCN 时，以下组件应能复用：

```text
RecPairDataset
BPR loss
negative sampler
popularity_debias_context
popularity_debias_head
component diagnostics
E0/E2 runner
```

换主干后只替换：

```text
z_core(u, i)
```

而不重写去偏分支和诊断链。

## 20. 最终判断

评阅意见总体合理，且应作为最终代码方案的约束条件。当前最关键的不是继续堆更多 loss，而是保证分数分解不可被 `self.b[t]` 这类 shortcut 绕过，保证训练和解释都在 logit space 中完成，并把 pedagogical need 从自由 MLP 改为教育适配 guardrail。

最终方案收敛为：

```text
2CKG4ER ConvE Core
+ BCEWithLogits
+ BPR with pedagogical distance-aware pairs
+ mixed popularity-aware negative sampling
+ global popularity nuisance
+ personal popularity nuisance
+ pedagogical relevance guardrail
+ popularity-subtracted debiased inference
+ raw/debiased E0 bias-chain diagnostics
```

该版本完成后，再考虑 CompGCN 主干升级，才更容易证明提升来自图传播还是来自去偏机制。
