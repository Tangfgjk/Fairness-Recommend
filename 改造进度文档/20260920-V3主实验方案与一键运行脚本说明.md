# V3 主实验方案与一键运行脚本说明

日期：2026-09-20

## 1. 实验目标

V3 主实验继续沿用原来的 Pre/In/Post 框架，但将 In-processing 从旧的全局 fairness regularizer 升级为 KPPD。

也就是说，主实验不再把旧 `in_only` 作为正式 In 模块，而是定义：

```text
In = KPPD-D3-Debias
```

因此主实验要回答：

1. 单独预处理是否能缓解资源流行度偏差？
2. 升级后的模型内 KPPD 是否比 baseline 更好？
3. 后处理是否仍能作为简单有效的去偏基线？
4. Pre + KPPD + Post 组合是否有进一步收益？
5. 这些方法是否在教育质量不明显崩坏的前提下降低热门资源偏差放大？

## 2. 数据集与随机种子

本轮只跑三个数据集：

```text
Eedi
algebra2005
XES3G5M-sub-small
```

随机种子先只跑：

```text
2024
```

单 seed 的目的不是最终显著性检验，而是筛选 V3 主实验路线。

## 3. 主实验方法

默认主实验包含 8 个方法：

| 方法名 | Pre | In | Post | 含义 |
|---|---|---|---|---|
| `baseline` | 无 | 无 | 无 | 原始 2CKG4ER / ConvE baseline |
| `pre_item` | item | 无 | 无 | 只用习题流行度预处理 |
| `pre_kc` | KC | 无 | 无 | 只用知识点流行度预处理 |
| `pre_item_kc` | item+KC | 无 | 无 | 习题+知识点预处理 |
| `in_kppd` | 无 | KPPD | 无 | 升级后的模型内去偏 |
| `post_only` | 无 | 无 | rerank | 后处理 quota rerank |
| `in_kppd_post` | 无 | KPPD | rerank | KPPD + 后处理 |
| `pre_in_kppd_post` | item+KC | KPPD | rerank | 预处理 + KPPD + 后处理 |

为了兼容旧命名，脚本支持别名：

| 旧名 | 新含义 |
|---|---|
| `in_only` | `in_kppd` |
| `in_post` | `in_kppd_post` |
| `pre_in_post` | `pre_in_kppd_post` |

但正式表格建议使用新名，避免误解为旧 fairness regularizer。

## 5. 一键运行脚本

新增脚本：

```text
Code/codes-New-ConvE/run_v3_kppd_pipeline.py
```

该脚本会自动完成：

1. 准备需要的 fair pre graph。
2. 训练 baseline / pre / KPPD 模型。
3. 导出 KPPD raw 和 debiased scores。
4. 对需要 post 的方法执行 quota rerank。
5. 统一评价 Ada/NOV 与资源曝光指标。
6. 运行 E0 偏差链诊断。
7. 聚合三数据集结果 CSV。

输出汇总目录：

```text
Code/runs/<batch-id>/
```

核心汇总文件：

```text
V3_main_metrics_all.csv
V3_main_fairness_all.csv
V3_main_E0_bias_chain_all.csv
v3_kppd_main_status.json
```

## 6. 正式运行命令

推荐正式命令：

```powershell

python Code\codes-New-ConvE\run_v3_kppd_pipeline.py `
  --datasets Eedi,algebra2005,XES3G5M-sub-small `

```

## 8. 结果解读顺序

建议按以下顺序分析：

1. `baseline` 是否存在明显热门偏差放大。
2. `pre_item / pre_kc / pre_item_kc` 哪类预处理更有效，教育代价是否可接受。
3. `in_kppd` 相比 baseline 是否降低 Item/KC Gini、提高 Coverage，同时 Ada/NOV 不崩。
4. `post_only` 是否仍是强后处理基线。
5. `in_kppd_post` 是否说明 KPPD 与后处理互补。
6. `pre_in_kppd_post` 是否形成当前最强组合。

论文或汇报中的主结论建议围绕：

```text
旧 In 模块升级为 KPPD 后，在教育相关性约束下显式扣除全局与个体流行度效应，
能够比单纯预处理或后处理更可解释地缓解资源流行度偏差放大。
```
