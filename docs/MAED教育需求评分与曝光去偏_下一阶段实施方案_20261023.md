# MAED 教育需求评分与曝光去偏：下一阶段实施方案（2026-10-23）

## 1. 决策与实施范围

采纳本次《曝光可行性实验审查与 MAED 下一阶段设计》的总体方向，分阶段实施，不直接将 FQE 贪心分配改写成训练损失。

研究问题：在原 SemanticConvE 基础上，先让推荐评分显式使用每位学生的教育需求，再验证教育需求条件下的曝光目标能否带来独立收益。

方法工作名 MAED，结构为 **原 ConvE + Q（教育需求评分）+ E（需求条件下的曝光优化）**。名称尚不代表方法已验证有效。

本文件记录实施前方案。首批 M0—M2 的实现、验证结果和运行命令见同目录 `MAED首批实现与运行说明_M0-M2_20261023.md`；正式模型训练尚未启动。

**质量标准后续修订：** 用户在前期结果已知后，将 NOV 允许绝对下降改为0.03，Ada仍为0.01。下一轮采用新标准，旧结果不覆盖；详细复评和当前入口见 `MAED质量预算修订与M1复评_Ada001_NOV003_20261023.md`。本文件历史可行性结果仍保留当时的0.01预算说明。

- 工作目录为 `Fairness-Recommend-New`，实施分支为 `maed-educational-demand-exposure-20261023-191247`，从 `merit-frequency-20261022` 创建。
- 原 KG4ER-New 目录保持只读，后续使用新目录独立的数据和历史模型副本。
- 保留原 ConvE、rec50 标签、BCE、负采样、25 轮、学习率、批大小及正式学生划分。具体参数继续从对应原始 config 读取。
- 正式 NOV 为 KG4Ex-NOV-Set；Top-N 为 5、10、…、50；Ep 展示 threshold=0.5。
- 暂不加入 KPPD、CompGCN 或新的 Post；E1-v1、E2 作为已有对照。
- 当前主任务是教育需求参照下的曝光偏差控制，不将其直接表述为因果去偏或学习机会公平。

## 2. 当前证据与不能推出的结论

固定 K=100、Top-10，已有结果：

|数据集|E0 DED|FQ DED|FQE DED|FQE 相对 E0 的 Ada 变化|NOV 变化|
|---|---:|---:|---:|---:|---:|
|Eedi|0.9214|0.4611|0.1650|+0.0148|-0.0055|
|Algebra2005|0.5424|0.4715|0.3354|+0.0229|-0.0086|
|XES|0.8697|0.4004|0.2212|+0.0366|-0.0094|

两档 K、两种分配、三个数据集共 120 个 N 位置均通过群体均值质量预算。但 FQ/FQE 使用测试学生教育状态、正确历史及测试人群规则曝光，属于探索性信息辅助分配；不是已训练模型，也不是严格最优上界。

FQ 本身改善明显，因此 Q 的收益和 E 的增量必须分开。FQE 优化 DED，不是最大化覆盖；不能要求其覆盖率必然高于 FQ。

实现核查：`scripts/merit_exposure_feasibility.py::allocate` 从 E0 排名分别运行 FQ/FQE。FQE 每次接受交换时要求所有受影响 N 的自身当前 DED 非增，且十档 N 平均 DED 严格改善。它没有以 FQ 为起点，也没有约束最终结果逐 N 优于 FQ。后者不是当前算法保证。

群体通过不等于个人安全。K=100、FQE、Top-10，NOV 下降超过 0.01 的人数为 Eedi 98/234、Algebra2005 40/144、XES 102/241。个人损失分布列入下一阶段必报项。

## 4. 第二阶段 M1：冻结 ConvE 的 Q 教育评分

### 4.1 首版评分定义

只使用同一类合法历史状态计算的 mastery、forget 和原教育距离，不重写学生编码。

\[
 m_{ue}=\prod_{k:Q_{ek}=1}M_{uk},\qquad
 d_{ue}=\sqrt{(0.8-m_{ue})^2+(0.8-F_{ue})^2}.
\]

原概率输出不能直接与 logit 相加，必须使用已保存的真实 logit 或模型 `score_logits`：

\[
 z_Q(u,e)=z_0(u,e)+\beta g(u,e),\qquad
 g(u,e)=-\operatorname{clip}\!\left(\frac{d_{ue}-a_d}{s_d},-c,c\right).
\]

`a_d`、`s_d` 只由训练学生状态确定，采用全局中位数和 IQR，退化尺度有显式下限；首版不对每名测试学生另拟合融合尺度。`c` 是预登记的截断常数。越接近教育目标，奖励越高。

首版 g 是固定、可解释项；暂不增加 MLP，也不将其称为已学习的教育需求分支。beta=0 精确恢复原排序。beta 的单位是 logit，不与旧 E2 概率校正的系数直接比较。

正式主比较对全部原候选习题使用同一评分排序。暂不把原 FQ/FQE 的 Top100 候选硬过滤带入 Q，否则候选变化与评分变化混在一起。可计算原规则 Top100 支持度，但它不是本版隐含筛选器。保留原历史题过滤政策与并列题号顺序。

历史答对知识点集合首版仅用于 NOV 和学生损失审计，不直接作为评分奖励，避免把评价目标混入 Q。

### 4.2 参数与诊断

先导出 E0 的训练学生真实 logit 矩阵，校准 g 与 z0 的尺度；Q 融合强度方案在查看新的测试结果前登记。

测试集不选 beta、温度或模型。参数如需选择，只使用明确的内部开发数据；从 E0 已参与训练的学生再划子集只能称训练侧诊断，不能包装成独立验证。若没有合格开发集，采用预登记固定设置并完整报告敏感性，结果仍为探索性，不能按测试成绩选最好值。

M1 无训练，比较 E0、Q-fixed 和规则参照，报告全部 N 的教育质量、DED、个体损失和列表变化。若只有很强 beta 才有效且原 logit 几乎不起作用，明确报告“规则主导”，不能据此宣称 ConvE 学会更强个性化。

## 5. 第三阶段 M2：曝光代理与真实 Top-N 的对应检查

### 5.1 需求目标的确定

采纳每个学生总需求质量相同的原则，但不直接把一份距离 Softmax 当成十个 N 的 Top-N 需求。

首版与当前 DED 定义对齐，构造训练学生的逐 N 规则目标：

\[
 q^{N}_{ue}=\frac{\mathbf1[e\in TopN(-d_u)]}{N},\qquad
 T^{N}_e=\frac1{|U_{train}|}\sum_{u\in U_{train}}q^{N}_{ue}.
\]

这保留了原 rec50 监督，但曝光辅助目标覆盖十档 N。属于显式引入教育规则先验，不是观测学习收益真值。建议中的距离 Softmax 可作为需求平滑敏感性分析，不能不加区分地替代逐 N 目标。

`T_train` 只能来自训练学生。测试人群规则曝光仅在最终 DED 评价中使用，不反向优化模型、beta 或停止轮次。训练目标与测试目标存在人群差异，训练损失下降不保证测试 DED 下降，两项分别报告。

### 5.2 只选择一种平滑 Top-N 代理

首版采用带数量约束的 Sigmoid 门控：

\[
 w^{N}_{ue}=\sigma((z_Q(u,e)-t_{uN})/\tau),\qquad \sum_e w^{N}_{ue}=N.
\]

阈值 `t` 逐学生、逐 N 求解；**梯度必须包含阈值对 logits 的依赖**，不能把求解后的阈值简单 detach，否则会破坏固定总曝光质量的梯度。温度过低时检查饱和、阈值解精度及梯度退化。

\[
 \widehat E^{N}_e=\frac{1}{|U|N}\sum_u w^{N}_{ue},\qquad
 L_E=\frac1{10}\sum_{N\in\{5,10,\ldots,50\}}
 \frac12\sum_e|\widehat E^{N}_e-T^{N}_e|.
\]

该代理用于训练辅助；正式推荐始终按同一 zQ 全题库稳定排序得到 Top50，所有 N 是同一列表前缀。软门控不是十份独立部署列表。

小批量计算时使用相同训练学生集合 B 的规则需求 `T_B^N` 对照其预测曝光，降低批次组成不一致产生的伪差异。均匀抽样学生，每人质量相等；批次大小固定且记录。小批量 TV 不是全体 TV 的无偏估计，按 epoch 审计完整训练人群的硬/软曝光，识别小批次噪声。

### 5.3 M2 如何验收

- 固定训练侧评分矩阵，分别测试共同项平移、等比例缩放、微小不跨名次扰动和确实跨 Top-N 边界的扰动。
- 检查每行权重和=N、平移不变性、自动梯度与有限差分、温度敏感性。
- 在矩阵上做少量诊断性优化步，记录软损失与真实各档 N 曝光、实际换题数；这不是模型训练，允许显式改动诊断矩阵副本，不改原模型参数。
- 再以真实模型可达的局部梯度方向做检查；自由矩阵可改善不等于 ConvE 参数化可实现。
- 尤其检查“只压缩分差而不改排序”的情况；若软损失明显改善但真实 Top-N 长期不变，本代理不通过，不进入 M4。
- 学生矩阵扰动和参数方向检查均只用训练学生；如展示测试侧诊断，另作探索性附录，不参与方法选择。

代理一致性是需实测的必要条件，不预设存在固定单调保证。实施前登记扰动集、优化步数、温度候选及通过判据。

## 6. 第四阶段 M3/M4：正式训练对照

### 6.1 实验组

|编号|实现|新增训练|用途|
|---|---|---|---|
|E0|原始 ConvE|已有，可复用同配置 seed2024|基线|
|Q-fixed / M1|冻结 E0 + 固定教育距离评分|无|拆出直接教育先验收益|
|Q-train / M3|ConvE 训练，rec 评分使用 zQ，其他关系保留原评分|有|教育信息进入训练的独立效果|
|QE-train / M4|与 M3 相同，增加曝光目标 LE|有|核心 Q→QE 去偏增量|
|E1-v1|上一轮匹配频率正则|已有|说明局部频率抑制的局限|
|E2-prob|上一轮概率频率校正|无|轻量传统式分数干预对照|
|E2-logit|真实 logit 上频率校正|无|评分尺度诊断对照|
|R / FQ / FQE|规则及原可行性分配|无|单列诊断参考，不参与正式最优排名|

M3/M4 均从相同初始化开始，使用同样 beta、尺度、教育状态和推荐候选；不是 M3 使用固定分数、M4 同时增加新网络。

\[
 L_{M3}=L_{BCE}(z_Q\ \text{for rec; original scores for other relations}),\qquad
 L_{M4}=L_{M3}+\lambda_E L_E.
\]

原 rec 标签和负例不变。不能只在推断时给 M4 加 Q，也不能对非 rec 的认知关系误加教育需求奖励。

沿用原参数、原 BCE 最优 checkpoint 规则；M3/M4 采用相同口径，额外报告最后轮次表现作诊断，不按测试公平指标选 checkpoint。seed2024 首轮训练共 2×3=6 组，E0 可复用；稳定性验证再使用原有 2024/2025/2026，不自动启动。

### 6.2 原训练接口的隔离

新增 `maed/` 和独立入口，复用已验证的模型装载、数据编号和原负采样。避免把新文件放入 `debias/*.py` 导致旧 source_digest 改变，从而使已完成实验恢复合同失效。新方法使用自己的源码/数据合同和新 run-id。

拟新增模块：

|模块|对外接口职责|
|---|---|
|`maed/state.py`|提供带来源、时点和用户范围校验的教育状态；模型侧不依赖评价文件|
|`maed/scoring.py`|统一 Q-fixed、Q-train、QE-train 的 rec logit，提供 beta=0 回退|
|`maed/exposure.py`|逐 N 需求目标、软 Top-N、曝光损失及完整人群诊断|
|`maed/training.py`|原 BCE 与新增项组合、受控前向、独立 RNG、断点续训|

lambdaE=0 时完全跳过曝光抽样和曝光前向，回退 M3；beta=0 且 lambdaE=0 时回归 E0。新增公平前向若使用冻结 BN/Dropout 行为，保留 autograd、异常安全恢复模式，并继承既有 cuDNN eval-GRU 回传修复。不得把 BN、随机数或缓存状态的变化混入公平增量。

## 7. 评价目标、质量保护和学生损失

### 7.1 预先登记主目标

- 核心目标：QE 相对 Q 的测试 **DED@10 下降**，同时展示其相对 E0 的变化。
- 所有 N 的 DED 和十档 N 平均变化完整报告，不因某一档变好宣称全面改善。
- Coverage、Gini、列表差异、CFP 是解释性次指标，不要求全部改善，也不按它们挑结果。
- 训练人群目标偏差与测试 DED 分列，防止将拟合训练需求误写为测试需求改善。
- 原测试集已被多轮分析，后续同集结论属于持续探索；即使从现在起登记设置，也不能宣称其是从未使用的确认性测试集。

### 7.2 当前质量预算（前期结果后修订）

每数据集、每 N 相对同轮 E0：Ada 绝对下降不超过0.01，KG4Ex-NOV-Set 绝对下降不超过0.03。原方案两项均为0.01；本次修改属于前期结果已知后的探索性调整，并从下一轮起固定使用。QE 相对 Q 的变化额外报告，不能只满足对 E0 的预算而掩盖对 Q 的大幅倒退。

预算是最终真实推荐的验收标准，不是 LE 自带的数学保证。首版不把离线全测试人群的预算计算放入推断算法，也不向每个用户强制施加同样的个人硬约束。

Ep@0.5 继续报告但不临时加入既有双指标预算；若显著恶化，作为限制明确说明，不因未列入硬门槛而省略。

### 7.3 学生尾部风险

对每学生定义正向损失 `loss_u=max(0,metric_E0(u)-metric_new(u))`。每 N 报告：

1. HarmRate：原始 delta < -0.01 的人数、比例（并列阈值处理固定）。
2. Worst10%Loss：取 `ceil(0.1×学生数)` 名损失最大者的平均正向损失，包含零，算法固定。
3. MaxLoss：最大正向损失。
4. 同时给出相对 Q 的上述结果，以及差值分布和配对不确定性区间。

首版这些是必须审计的风险指标，不预设未经验证的硬阈值。若 QE 比 Q 加剧尾部损失，即使 DED 降低也不能宣称学生层面公平改善；下一版单列尾部约束消融。提前说明这一机制，不能事后将坏结果藏在群体均值后面。

## 9. 成败判定

- **Q 有效、QE 无增量：** 教育信息接入有效，曝光方法尚无必要性证据，不把 Q 的收益归于去偏。
- **软代理下降、真实排序不变：** 不继续扩大训练，修正曝光代理及其与评分参数的接口。
- **训练曝光改善、测试 DED 不改善：** 检查需求人群迁移与参数泛化，不用测试曝光改写训练目标。
- **DED 改善、质量超预算：** 未达到当前研究目标；调整需形成新、预登记的方案版本。
- **群体达标、部分学生伤害增大：** 报告资源曝光收益及其个体代价，不能称已解决学生公平。
- **Q→QE 有独立增益、各 N 质量达标且风险可解释：** 再进行多种子验证；随后才考虑 CompGCN。

本轮建议先授权并完成 A—C，而不是立即启动 M3/M4 训练。目标是先确认教育信息和曝光目标确实连接到可用、可学的评分机制。
