# 教育适配条件下的频率去偏：完整实施方案（2026-10-22）

本文是实施计划，不代表新增方法已经实现或有效。依据本次讨论的最终选择：先在原 SemanticConvE 上验证训练内去偏，再研究 CompGCN；正式 NOV 使用 KG4Ex-NOV-Set。

**1. 研究任务与工作边界**

研究问题：当两道习题对同一学生的教育适配代理相近时，模型是否仍给训练 rec 高频题过大的评分优势？能否通过受限训练正则减弱这种优势，同时保持教育推荐质量？

研究定位暂定为“教育适配性条件下的伪标签频率偏好抑制”。rec 是教育规则生成的监督标签，rec 频率不同于历史练习人数。高 rec 频率也可能是合理教育需求的表现，因此高频本身不是要消除的对象。

**4. 先补齐诊断与可匹配性检查**

频率定义为训练图中推荐某道题的不同训练学生数：

\[
f_e=|\{u:(u,rec,e)\in T_{train}\}|.
\]

同时保存三元组原始次数并检查重复边；在当前图无重复 rec 边时二者一致。历史练习人数作为诊断变量独立存储，不参与首版去偏强度定义。训练频率、归一化参数、匹配阈值只能来自训练部分。

从正式图读取全精度教育距离：

\[
M_{ue}=\prod_{k\in K_e}m_{uk},\qquad
d_{ue}=\sqrt{(0.8-M_{ue})^2+(0.8-F_{ue})^2}.
\]

`stu2ex_recommend_full_precision.json` 是排序和距离匹配依据。其他掌握/遗忘文件按保存精度使用，并在清单记录；不能用两位小数关系编码代替全精度距离。

单独匹配 d 不够：相同 d 可能由不同掌握度和遗忘度组合形成。因此题对条件同时检查 d、掌握度乘积 M、遗忘度 F、知识点数量，并报告难度/区分度与 KC 集合的残余差异。条件匹配只能提高可比性，不保证等同的教育价值。

本次已做一个不训练的可行性探查：只在每名训练学生原有 50 个 rec 正例中组成无序题对，要求 `|Δd|≤0.02`、`|ΔM|≤0.05`、`|ΔF|≤0.05`、知识点数量相同，且 `|log(1+f_h)-log(1+f_l)|≥log(2)`。

| 数据集 | 合格题对 | 有题对的训练学生 | 每学生题对中位数，含零 | 再要求 KC 集合完全相同后的题对 / 学生 |
|---|---:|---:|---:|---:|
| Algebra2005 | 19905 | 214/430 | 0 | 15616 / 139 |
| XES | 103826 | 673/727 | 88 | 4296 / 115 |
| Eedi | 36564 | 257/701 | 0 | 4622 / 79 |

这是初始支持度统计，不是方法效果；尚未匹配 IRT 难度、区分度。知识点数量相同也不等于知识点相同。不能为了使覆盖率漂亮而在测试集上放宽条件。

接下来输出诊断：按学生/频率分位/KC 数量的支持度；题对难度与区分度差异；相近 theta 但认知向量不同的学生推荐差异；固定题对的频率胜率；正负采样次数及其与模型分数的关联。没有题对的学生保留在正常 BCE 训练和全部测试评价中，公平项为无适用样本，不能记作已经成功去偏。

阈值可以先扫描训练数据上的少量更严/更松设置，但只依据匹配平衡与支持度锁定。上述数值作为首个探查配置，不预先宣称最终最优。若加入属性匹配后支持度太低，应缩小方法适用范围或承认识别不足，不直接跨越明确的教育标签差异配对。

**5. 首版训练内方法**

临时方法名：教育适配匹配的频率偏好抑制。先使用原模型架构。

训练题对 `(u,h,l)` 满足：同一训练学生；两题均为其原训练 rec 正例；教育条件满足已锁定的匹配限制；`h` 的训练 rec 频率高于 `l`，频率差超过阈值。首版不混合正负标签，也不把未入 Top-50 的题自动视为教育等价正例。

采用原模型 sigmoid 之前的分数 z：

\[
\ell(u,h,l)=[\max(0,z_{uh}-z_{ul}-m)]^2,\quad m\ge0.
\]

先在每名有匹配题对的学生内部平均，再对这些学生平均：

\[
L_{fair}=\frac1{|U_P|}\sum_{u\in U_P}\frac1{|P_u|}\sum_{(h,l)\in P_u}\ell(u,h,l),
\qquad L=L_{BCE}+\lambda L_{fair}.
\]

这一项只限制可比条件下高频题过大的分数差，不要求低频题一定排前，也不宣称已识别因果偏差。m 允许保留小幅差异；首版测试 m=0 的简单约束，并将正 margin 作为预登记敏感性设置。最终 λ、m 应在工程探针后登记，不能凭空宣布最佳默认值。

工程接入方式：

- 保留原 BCE 前向、数据遍历、负采样和优化器更新步数；在含 rec 的训练 batch 上附加公平项。
- 公平采样使用独立随机数生成器，先均匀选有题对的训练学生，再均匀选其题对。首个算力预算可设每步最多 32 名学生、每学生最多 4 对；按实际有效人数平均。缓存题对只保存整数索引及审计属性。
- 公平评分将同一学生的一对候选放在同一次评分中；首版公平分支临时使用 eval 行为，固定 BN 统计并关闭 dropout，但保留 autograd。完成后恢复所有子模块状态。普通 BCE 仍使用原 train 行为。这样不会因为额外前向更新 BN 统计或噪声掩码而混入另一个干预。
- λ=0 时完全跳过公平采样和公平前向，满足原实现回归；不能只把已执行的额外损失乘零。
- 公平分支不使用 `no_grad`，记录其梯度是否到达 ConvE、实体编码和尾偏置。
- 每个 epoch 分别记录 BCE、公平损失、有效学生/题对、激活惩罚比例、梯度范数、logit 方差、训练耗时。
- best checkpoint 继续按原平均 BCE 选择；同时保存 total/fair 曲线和 last checkpoint。不同 λ 的总损失不能混作统一的“最佳”选择标准。
- 断点保存新采样器状态和公平配置哈希；原始断点缺少新状态时不能冒充同配置续跑。

重要能力边界：正例内配对不会直接为 rec 频率为零的题建立正向推荐依据。约束共享的评分器也不能补回输入中缺少的学生知识点向量。如果损失降低但实际列表仍一致，应如实判为首版不足；不要靠复制规则排序掩盖这一结果。

**7. 正式评价定义**

教育指标为 Ada、KG4Ex-NOV-Set、Ep@threshold=0.5，均报告 N=5:5:50。不同方法全部通过同一新入口重评。

NOV 定义固定为：

\[
K_u^N=\bigcup_{e\in TopN(u)}K_e,\quad
NOV_{Set}@N=\frac1{|U|}\sum_u\left(1-\frac{|K_u^N\cap C_u|}{|K_u^N\cup C_u|}\right).
\]

`C_u` 为该学生原协议中已有历史答对习题的知识点并集；沿用现有报表脚本对 `interactions_all.csv` 的历史口径。这是学生划分下的历史信息，不得额外使用一个未来留出目标窗口。空正确历史但推荐知识点非空时 NOV=1；并集也为空则报数据错误，不能默默赋零。XES 使用当前 corrected/compact 数据副本。旧时间加权 NOV 可作归档复核，但不作为新表正式 NOV。

Ada 保留原定义与读取精度。需要特别区分：匹配用 M/F/d 的保存值，原 Ada 从测试认知关系读取掌握度值，两者不保证逐值相同。不能为了正则便利悄悄改 Ada 评价。Ep 直接复用 `mastery_ep_v2` 的评价函数及冻结上下文；旧 comparison CLI 强制四个 threshold，因此新 wrapper 直接调用已有函数选择 0.5，或计算四个后仅呈现 0.5，不传一个会被原 CLI 拒绝的参数。

公平与诊断指标：

| 指标 | 计算与解释 |
|---|---|
| CFP | 固定条件匹配题对中高频题胜率；相同分数计 0.5；先学生内平均，再学生间平均；报告有效学生和题对数。另报频率优势 logit 差 |
| DED@N | 模型 Top-N 曝光分布与同学生教育规则 Top-N 曝光分布的总变差距离 `0.5*sum(abs(E-D))` |
| Item Gini/Coverage | 按完整候选题库计零曝光题；覆盖率分母固定为候选题库大小 |
| KC Gini/Coverage | 每次题目曝光按其知识点数量均分；KC 分母固定为可推荐题目涉及的知识点全集，记录具体数量 |
| UniqueListRatio | 同时报有序列表比例和无序集合比例，避免仅交换题序造成“个性化提升” |
| 用户间列表差异 | 平均 Jaccard 距离，结合认知差异分组与规则参照解释 |
| 规则重合率 | 每学生模型 Top-N 与规则 Top-N 的交集数/N，再平均 |

CFP 的评价题对在训练前锁定，选择过程只看训练频率和原协议允许的学生历史状态，不能看模型分数。主评价可采用规则 Top-50 内的匹配题对，对应正例内训练范围；同时报告更广候选范围中教育条件相近的补充题对，并区分规则 Top-50 内外。测试规则 Top-50 是离线参照，不是新增测试训练标签。没有合格题对时报告 NA，不填写 0 或 0.5。所有方法、种子共用同一评价池。

CFP 不直接标“越低越好”。接近 0.5 表示匹配池内没有明显单向胜率，但过度低于 0.5 可能是反向偏好；仍存在未控制的教育差异。全体分数相同也会给出 0.5，因此必须同时检查真实排序、分数方差和教育指标。

DED 小表示更接近规则的总体曝光，不等于真实学习收益或个体公平。不同学生错误交换推荐列表也可能保留相同总体曝光。规则本身 DED=0 是定义结果，故规则参照必须作为一行单独展示，不能用 DED 独自宣布胜出。

本方案采用未按位置折扣的 Top-N 曝光，以便与现有诊断一致；若扩展位置曝光，另立版本并将模型与规则使用同一折扣，不能混报。

| E4 | E1 的同一匹配题对，但高低频惩罚方向随机固定 | 是 | 收益是否仅来自压缩分数差，而非有方向的频率抑制 |
| R | 原教育距离排序 | 否 | 教育规则参照及 DED 的解释锚点 |

E2 使用固定的训练频率归一化和原概率评分，单独记录 λ_score，不与训练 λ 混用；输出分数只作排名，不声称仍是校准概率。E3 保留两题都是正例、频率差、有效学生集合、每学生采样预算、损失权重等，只撤去教育匹配；否则会同时改变适用人群和训练强度。E4 固定独立随机方向，评价仍按真实高低频定义 CFP。

先完成全三数据集零训练重评与数据诊断，再按 Eedi → Algebra2005 → XES 做 seed 2024 工程/探索运行。Eedi 规模较小，但其匹配覆盖较低；Algebra2005 的多知识点题是质量风险检查重点；XES 验证方法是否可迁移。

按每组一个固定配置：E1/E3/E4 共 3 个新训练组 × 3 数据集 = 9 次单种子训练；扩展三个种子总共 27 次。若 E0 也在同环境完整重跑三数据集三种子，合计 36 次训练。E2、R、归档重评不算训练组。短程回归和参数敏感性运行另列，不隐藏在正式训练次数中。

不预先重跑原来的六组教育消融和全部八个传统对比模型。第一阶段先回答机制问题；如需要论文横向对比，可导入相同协议的既有分数统一评价，并清楚区分“效果比较”和“去偏机制归因”。

**9. 参数、测试集使用和验收规则**

原训练设置固定。新增匹配阈值在训练数据上看支持度和属性平衡；公平 λ、margin、每步采样预算预登记。建议初始敏感性范围采用少量值，例如 λ={0.01,0.1}、m={0,0.1}，这是 logit 正则的探索范围，不是已经验证的默认最优值。先通过小规模训练检查量级、有限梯度和原 BCE 是否被压制；正式主配置在查看新增测试结果前写入配置文件。

本项目目前按正式训练/测试学生划分使用，不能把已经进入模型训练的学生临时称为独立验证集。如果保持现有划分且不增加训练内部验证流程，就固定配置并完整报告预登记敏感性结果，不在测试集反复挑最佳。若后续确需数据驱动选择超参数，再设计仅位于训练部分的内部选择流程，并明确冻结前端特征已看过哪些数据；最终正式训练仍用完整原训练集。

此前测试结果已参与研究方向选择，因此本阶段测试证据应视为探索性；换随机种子不能使同一测试学生成为全新独立验证。论文需说明这一点，而不是把种子数当作消除选择偏差的办法。

工程通过标准：

- λ=0 不增加随机数消耗、不更改 BN 缓冲，固定环境的小型回归对比损失、梯度、分数与排序；原历史跨设备结果采用数值容差，并记录 Top-N 差异。
- 频率只用训练学生；训练题对不含测试 UID；实体/Q/历史映射无缺失与重复；候选分数全为有限数。
- 公平项有非零梯度；无配对学生与空 batch 正确跳过；无正负标签冲突；重启续跑配置完全一致。
- Top-N 从同一 Top-50 排序取前缀；NOV、DED、CFP 使用手工可核对的小例子测试；CFP 全并列为 0.5、无题对为 NA，DED 同分布为 0。

研究通过标准：

- E1 在锁定匹配池上减少原有高频优势，并在实际 Top-N 曝光/覆盖上产生相应变化；只降低训练损失不算成功。
- Ada、KG4Ex-NOV-Set、Ep@0.5 同时检查。正式判定之前锁定可接受损失预算；可先讨论各指标绝对下降 0.01 的操作阈值，但这不是教育学公认阈值，也不能只报告通过的 N。Ep 接近零时同时报绝对和相对变化。
- E1 比 E2/E3 呈现更好的教育质量—曝光权衡；E4 若效果相同，应将机制解释收缩为一般分数差约束，而非频率特异的去偏。
- 三个数据集分别报告，不能用平均值掩盖某一数据集退化。三种子报告均值和样本标准差；学生层面配对 bootstrap，曝光指标每次重采样后重算分布。不能把同一学生的多个题对当独立样本进行显著性检验。
- CFP、DED 与训练损失存在相关设计，因此必须同时给真实 Top-N、教育质量、用户级/频率组级明细及反向偏好检查。

可能的结果也预先明确：若只是分数变平但列表仍集中，首版方法不足；若 Gini 降低但 Ada/Ep 明显受损，不定为主模型；若多数学生没有可比题对，不把局部效果外推到所有学生；若认知差异仍无法进入评分，则后续单独开展表示增强对照。

**10. 交付与后续 CompGCN**

第一批交付：基线来源清单、统一评价 JSON/CSV、匹配支持度与条件频率诊断报告、锁定的配置与测试题对。这批不重新训练。

第二批交付：default-off 训练接入、梯度/零权重回归测试、E0–E4 执行入口与断点清单；之后才运行授权的正式训练。

第三批交付：每数据集每指标一表，教育与公平表分开；三种子先对学生平均再聚合。高优/低优指标按其方向标最优和次优；CFP 和 UniqueListRatio 以诊断展示，不机械加粗最小/最大值。所有表保留方法、种子、数据哈希、NOV 定义、Ep 阈值、候选池版本。

方向一完成后，CompGCN 阶段采用四格对照：ConvE、ConvE+Debias、CompGCN+ConvE、CompGCN+ConvE+Debias。公平模块仅依赖学生/习题索引、logit、训练频率和教育匹配上下文，可直接复用。图传播必须另行检查训练/测试学生编码路径、合法历史接入、关系映射、1/2 层传播与残差；不能把 CompGCN 自动视为公平改进。

**11. 证据与方法来源**

本计划中的匹配 hinge 正则、CFP/DED 组合及具体实验矩阵是拟议研究设计，尚无有效性结论。CFP、DED 是工作名称；DED 的公式是总变差距离。

曝光分配与推荐效用需要共同考虑，可参考 [Fairness of Exposure in Rankings](https://arxiv.org/abs/1802.07281)。该论文支持研究视角，不证明本计划中的教育距离就是正确公平价值。

CompGCN 的实体—关系联合传播来源于 [Composition-based Multi-Relational Graph Convolutional Networks](https://arxiv.org/abs/1911.03082)。本阶段尚不实施图编码器。
