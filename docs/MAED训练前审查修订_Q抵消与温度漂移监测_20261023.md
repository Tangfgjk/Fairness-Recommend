# MAED训练前审查修订：Q抵消与温度漂移监测（2026-10-23）

## 1. 修订范围

依据本次《MAED最新训练版本审查》，补充训练期间的机制监测，保持原ConvE、原BCE监督标签、负采样、25轮、学习率、batch size及原划分不变。beta=0.5、lambdaE=0.01继续固定，温度仍只用训练学生的冻结E0+Q标定，不动态调整。主checkpoint仍按最低监督BCE选择，last单独报告。

Q被BCE抵消、固定温度随训练失配是需要实验验证的风险，尚不是已确认发生的错误。本次增加可观察证据，不预先更改目标或承诺问题已经消失。

不加入KPPD、CompGCN、Post或额外质量损失。不启动六组正式训练。

## 2. Q作用与潜在抵消

`maed/training_monitor.py`使用固定、最多48位均匀抽取的训练学生，所有模型和轮次使用同一集合。初始化及每轮末记录：

- core真实logit、固定Q奖励、融合logit各自的均值、标准差及学生内标准差。
- 三项的习题平均分与训练rec频率的Spearman相关；分别报告全题库及频率大于0的习题。常数向量相关性记为null。
- 频率从训练triples中的rec边计数，拒绝重复边或测试学生rec边，不使用历史练习热度替代。
- core与Q奖励的学生内中心化回归斜率；core相对初始化的变化对奖励的斜率及中心化Spearman。变化斜率接近-1与抵消相容，但并非因果证据，需结合排序增量判断。
- 每个N下，core与fused的集合重合率、集合发生改变的学生数、次序发生改变的学生数、两者硬DED及平均教育距离。

core与fused来自同一时刻的同一组参数，是推断时Q项的直接消融。它不能单独解释“加入Q训练”导致的因果变化；最终仍比较Q-fixed、M3和E0。Q只直接修改rec评分，非rec接口未改。

## 3. 温度与真实排序对应

固定温度不重新估计；每轮逐N报告：

- 第N与N+1名分差的中位数、零分差比例、分差中位数除以冻结温度。
- 该比值相对同一训练初始化审计的变化。
- 软Top-N总质量中落在真实Top-N内的比例。
- 同一训练子集、同一教育规则目标下的软曝光TV与硬DED。

探索性提示：比值相对初始化变化超过4倍或小于1/4，或真实Top-N承载的软质量低于0.80，写入逐N标记及`mechanism_warning_Ns`。初始比值为零而随后非零也标记。零分母不伪造有限倍率。

这些阈值仅帮助发现尺度变化，既不是理论阈值，也不触发停止训练、重新标定温度、调整lambdaE或选择checkpoint。即使软质量很高，也不保证梯度有效或实际DED下降，仍需结合软/硬指标、梯度和最终列表判断。初始模型与温度参考E0属于不同训练时刻，因此初始化就出现提示并非自动判错。

## 4. 曝光梯度监测

每轮记录实际含rec、确实执行曝光辅助损失的批次中的首个、居中的一个（偶数时取靠前者）、最后一个：

- BCE梯度范数、乘lambdaE后的曝光梯度范数及二者之比。
- BCE与曝光梯度的余弦相似度及角度（度）。
- 全局batch序号、有效曝光batch序号和first/middle/last角色。有效批次不足3个时合并角色，不重复反向。

使用原采样器产生的同一份批次顺序做定位，不进行第二次洗牌、不额外读取负样本、不额外抽取曝光学生。`autograd.grad`保留计算图且不写入`.grad`，随后仍只执行一次联合backward和一次原Adam更新。lambdaE=0完全跳过曝光目标、曝光采样器及此批次包装。

## 5. 初始化、恢复和文件

新增`initialization_audit.json`，包含seed、初始完整模型state哈希和上述初始审计；同参数同seed的M3/M4应有相同初始哈希。恢复时仍由源码/配置/资产合同保护，参考初始模型重新按同seed构造，再恢复最后完整epoch的权重、优化器和随机状态。

每轮`epochs/NNN.json`的`training_exposure_audit`和`gradient_balance`保存完整诊断。最终报告额外导出：

|CSV|用途|
|---|---|
|training_initializations.csv|检查M3/M4初始化来源一致|
|training_score_components.csv|逐轮Q/core/fused与频率关联及潜在抵消|
|training_boundary_alignment.csv|逐N分差/温度、软硬曝光对应、Q排序增量|
|training_gradient_balance.csv|前中后有效批次梯度比例与夹角|

CSV列中的`training_users`是审计子集人数；完整UID列表保留在对应JSON中。所有审计只用训练学生，不读取测试评价标签。

## 6. 验证记录

本次12项训练检查通过，其中包含：

1. 原rec接口与训练/推断Q一致性，非rec不被Q直接修改。
2. beta=0、lambdaE=0时原单步行为回退；M4零曝光权重与M3的权重、优化器及随机轨迹一致。
3. M3与正权重M4的初始化哈希一致；合成小图的完整训练和断点恢复一致。
4. 监测不改变参数、BN缓冲区、已有梯度、混合train/eval模式、Python/NumPy/Torch随机状态。
5. 人工抵消案例中，core变化斜率为-1且Q排序增量消失；尺度漂移能够被标记。
6. 原DataLoader与监测批次包装的样本序列和交错随机数完全一致。
7. 相反梯度的夹角余弦为-1，监测后联合backward结果保持正确。
8. 真实Eedi单批1024监督样本加16位训练学生全题库曝光的CUDA联合反向、梯度统计和训练审计通过；无优化器更新。
9. 训练诊断CSV可导出，M4的报告直接参照仍为M3。

上述合成流程测试和单批工程检查不属于六组正式实验，不提供训练效果结论。三数据集正式输入预检另外执行`--stage prepare`，不产生训练checkpoint。
