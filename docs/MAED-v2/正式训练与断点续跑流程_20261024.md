# MAED-v2 正式训练、续跑和统计流程

日期：2026-10-24。基于本分支已完成的 P0；不修改 MAED-v1 冻结内容。

## 1. 本次补齐的实现

- `maed_v2/training.py`：C0/C3/C4 训练、原始负采样与概率 BCE、Q 统一融合、正权重 D/E、训练侧监测、best/last、epoch 零检查点与完整 epoch 重放。
- `maed_v2/preflight.py`：三数据集真实 CUDA 正权重 C4 单步及真实 Eedi 多批次非整轮失败重放。
- `maed_v2/audit.py`：训练完成的 C0 固定权重干预；完整 B、保留图/度/自环的关闭邻居消息、同一 C0 权重的原语义路径。只复算轻量教育/曝光指标，不重复 Ep，不是额外训练组。
- `maed_v2/report.py`：逐指标论文表格、最佳/次佳、A/B 正式对照、E0/M3/M4 等历史参照、质量预算、学生损失、训练梯度/温度/Q 抵消诊断。
- `scripts/run_maed_v2_training.py`：计划、准备、预检、正式训练与评价编排、续跑及报表入口。
- `scripts/run_maed_v2_all.ps1`：一条命令检查并运行全部流程；续跑跳过已完成门槛和实验。

## 2. 固定实验矩阵

顺序：Eedi → Algebra2005 → XES3G5M-sub-small；每个数据集 C0 → C3 → C4。

|方法|结构|正式训练|
|---|---|---|
|C0|原 feature_only 初始化 + 单层 mult Semantic-CompGCN + 原 ConvE 解码|25 轮|
|C3|C0 结构 + Q|25 轮，从原初态重新训练，不加载训练后的 C0|
|C4|C0 结构 + Q + D/E|25 轮，与 C3 同初态|

三数据集共 9 组，仅 seed 2024。保留 bs=1024、negative ratio=5、lr=0.001、原 Adam、最低监督 BCE 选 best。Q beta=0.5、clip=3；曝光权重=0.01、辅助学生=16、Top-N=5,10,...,50。不加入 KPPD、Post、covers 或新损失，不按测试表现提前终止或调参。

C0/C3/C4 的每个 best/last 均导出完整 B 和同权重 A；A/B 不计额外训练。主表必须有 C0-A、C0-B、C3-B、C4-B；C3-A/C4-A 及 last 单独保留。新输出为排序 logit，下游按排序评估；Ep@0.5 是模拟答题阈值，不是该 logit 的阈值。

## 3. 温度与状态边界

C0 完成后，仅用其 best checkpoint、训练基图、全部训练学生，计算 C0+Q 的十档边界温度。保存为 `assets/<数据集>/C0_reference/assets.json`；C3/C4 及续跑直接读取并验证，绝不重新标定。GPU 归约可能产生末位变化，所以即使同一个 checkpoint，也不能每次启动都重新计算温度再企图逐位匹配。

测试学生状态只在 no_grad 推断中逐人扩图，不进入监督 DataLoader、辅助学生采样或温度标定。完整 B 是正式路径；局部参考有排序边界差异，不用于正式结果。历史末端快照/传导式预处理限制仍保留，不声称严格未来预测或因果隔离。

## 4. 断点恢复合同

`last.pt` 保存模型、Adam、Python/NumPy/Torch/CUDA RNG、独立曝光采样 RNG、固定监测参照、完整 epoch 编号、best 信息、图/配置/源码身份。

第一次训练前先保存 epoch=0；以后仅在完整 epoch 结束后替换 last。若任意 batch 后失败，重新执行同一命令，会读取上一个完整 epoch，重建 DataLoader 并重放该 epoch。不会把半轮更新当作完整成果，也不会从其他方法的参数续训。

源码、图、配置、温度或 checkpoint 身份变化会拒绝续跑，必须另用 run-id；不静默混合结果。λE=0 路径完全跳过曝光对象、采样、前向，已通过 C4 与 C3 的回归。

2026-10-24 来源加固版进一步在 checkpoint 内保存独立 `source_hash`、完整 `contract` 及其摘要。恢复、独立加载、分数导出、温度缓存和机制缓存均先核验来源；缺少收据的历史 checkpoint 拒绝直接用于新版。正式分块强制固定为 Eedi=4096、Algebra2005=65536、XES=131072，不启用未通过的分块或局部推断。

## 5. 工程问题及修复

1. **CPU 多线程归约不是逐位确定的。** 真实 Eedi 图的重复索引 gather/backward 在 2 线程可出现约 1e-8 的梯度末位差异，放大后造成参数微差；相同前向、相同 RNG 不保证逐位梯度相同。真实中断重放的严格验收使用单线程 CPU，并在结束后恢复线程数。正式 CUDA 仍沿用原非确定性设置，不夸称 GPU 逐位复现。
2. **新增图参数初始化隔离 GPU RNG。** `torch.manual_seed` 同时重置 CUDA，而 `fork_rng(devices=[])` 不恢复 CUDA。现在只对 CPU 默认生成器设种子来初始化新增矩阵，CPU fork 恢复后也不影响已推进的 CUDA RNG；新增了先消耗 CUDA 随机数再核验的回归测试。图结构、公式及 CPU 初始化矩阵不变。旧 P0 文档保留为当时证据，新训练以前置门槛和当前源码哈希为准。
3. **温度只生成一次。** 已保存的 C0 温度只做来源检查，不在 C4/续跑时重算，避免 ULP 差异导致合同漂移。
4. **监测数值不冒充不可变合同。** 初始化只强校验真实权重哈希、seed 和合同；GPU 重新计算的监测摘要允许末位差异，原始记录保留。断点中保存并恢复监测初始参照，避免这些观察量的舍入差异阻止合法续跑；没有放宽配置或权重身份校验。

这些修改均是实现一致性修复，没有依据测试推荐指标修改方法。

## 6. 一键运行与续跑

正式训练由用户手动启动。新版默认使用 provenance 目录，首次运行需重新通过当前源码工程门槛；旧 controlled 门槛是旧源码证据，不能当作新版验收。此前 release 目录的半轮尝试已中断，不作为新版正式结果或续跑来源。

```powershell
$repo = 'C:\Users\21709\Desktop\Fairness-Recommend\Fairness-Recommend-New'
Set-Location -LiteralPath $repo
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\run_maed_v2_all.ps1
```

同一条命令用于续跑；已完成实验校验来源后跳过。只看计划：

```powershell
& .\scripts\run_maed_v2_all.ps1 -Plan
```

若 PowerShell 执行策略阻止脚本，可直接使用 Python（环境和门槛已验证时）：

```powershell
$py = 'C:\Users\21709\.conda\envs\rtx5060\python.exe'
& $py -u .\scripts\run_maed_v2_training.py --stage run
if ($LASTEXITCODE -ne 0) { throw '实验中断，请检查当前 stage.log，再用同一命令续跑' }
```

首次还没有门槛时，先使用 `--stage preflight`；已有通过的门槛无需反复执行预检。源码变化时不要复用原目录。

## 7. 文件位置及结果解释

正式目录：`runs/maed_v2_semantic_compgcn_seed2024_20261024_provenance/`。

- `protocol.json`：固定设定和源码身份。
- `engineering_gate.json`：真实正权重 GPU/真实数据重放验收。
- `status.json`：当前数据集、方法、阶段及运行/中断/完成状态。
- `<数据集>/<C0|C3|C4>/seed2024/epochs/`：每轮原始监测。
- 同目录 `best.pt` / `last.pt`：模型和完整续跑状态。
- `best|last/inference_B|A/`：分数、逐学生图身份、评价、Ep 及来源哈希。
- C0 同目录 `diagnostics/best_C0/`：固定权重机制对照及学生/候选表示变化。

报表：`runs/论文格式文档统计/maed_v2_semantic_compgcn_seed2024_20261024_provenance/`，每数据集一个逐指标 HTML，另有全指标 CSV、逐 N 的 Ada/NOV 预算、学生损失、CFP 和机制诊断。只保留 Ep@0.5；NOV 固定 KG4Ex-NOV-Set。R 不参与最优/次优标记；单种子没有跨种子标准差。

随时重建已完成部分的表格：`python scripts/run_maed_v2_training.py --stage report`。主表不会把未完成组伪装成完整实验；报告清单有 `all_nine_stages_complete` 字段。9 组训练、导出、评价和机制阶段均完成后，根 `status.json` 才写 complete。

质量参考预算仍逐 N 相对 E0 检查：Ada 绝对下降≤0.01，NOV 绝对下降≤0.03。是否达标、Algebra2005 的取舍以及 C4−C3 的曝光增量，均由实际结果判断，不由损失下降或代码通过测试代替。
