# MAED-v2 P0：设计基准与实现范围

日期：2026-10-24。分支：`maed-v2-semantic-compgcn-20261024-152715`。

## 1. 本轮范围

依据同目录《Semantic-CompGCN升级实施方案_20261024.md》及用户最终审查，完成 P0-1～P0-4 工程实现。该方案正文保留为设计时点记录；实际执行状态以本文件及《P0工程验收结果_20261024.md》为准。

本轮不启动 C0/C3/C4 的 25 轮正式实验。工程显存、梯度与吞吐测试会在临时模型上执行有限 Adam 更新，每档恢复相同初态、相同 RNG、相同固定训练 batch；测试后丢弃更新、恢复初态，不写正式 checkpoint。所有测试学生推断均为 eval + no_grad，无参数更新。

MAED-v1 的 `maed/`、`debias/`、原 ConvE、原数据集、历史结果、冻结规范及 `CONTEXT.md` 不修改。新增内容位于 `maed_v2/`、新脚本、测试及本目录。

## 3. 正式 B 与局部参考

完整 B 对每个查询构建独立图，重新计算双向度、全部实体表示及当前学生的全题库分数。候选习题表示允许随查询改变。A 使用同一参数、固定训练图，测试学生精确保留语义初态。

首版局部实现采取**评分接收节点子集的精确重聚合**：只物化当前学生与全部习题输出，仍用完整扩图的真实度、完整邻居及 H0/R0 求和。因此不会省略旧边因度变化产生的权重变化，也不会将 H1 作为本层消息源。它尚未实现方案中的“缓存基图预聚合 + 度差增量”加速；本轮不把它称为该增量内核。

局部表示带有效行掩码，其他行不可用于评分。与完整 B 比较全部评分行、logit 和每个 N 的稳定排序。任何一项不一致即不接受该查询的局部结果。**当前实际导出及成本测量始终使用完整 B 参考**，即使局部测试通过也不切换正式输出。

CUDA `index_add` 采用原子归约，同图重复前向可能有末位差异。按预设 GPU 容差 `atol=1e-5, rtol=1e-4` 核验并单列 Top-N；CPU float64 分块/梯度采用 `atol=1e-9, rtol=1e-7`。不通过调整分数精度或并列规则掩盖差异。

## 4. 量化状态审计

图关系由原始状态量化至两位小数，Q 使用保存到六位小数的状态。恰落在半分位边界时，两者格式化结果可能差一档。实现只接受距对应半分位不超过六位小数存储误差的情况，并保存数量、来源行和实际值；其他不一致直接失败。不修改原关系、状态或评价文件。

训练文件必须已删除 `exfr0.00`；查询文件保留原样，派生图过滤同名零关系。`mlkc0.00` 保留。仅凭排除 rec 不能声称状态和伪标签独立，历史末端快照的解释边界继续沿用。
