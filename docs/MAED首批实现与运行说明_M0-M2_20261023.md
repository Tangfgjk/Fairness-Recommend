## 2. 新增代码

|文件|职责|
|---|---|
|`maed/state.py`|不读取评价标签或正确历史的模型侧教育状态；验证 Q、学生编号、教育距离；仅允许训练学生构造曝光目标|
|`maed/audit.py`|M0：历史时点、共享标定、checkpoint/清单证据、状态一致性、SHA-256 来源审计|
|`maed/scoring.py`|训练学生拟合中位数/IQR；真实 logit 上融合固定教育评分；beta=0 原样返回|
|`maed/model.py`|只读加载同轮 E0，导出训练学生 logit；不创建 optimizer|
|`maed/exposure.py`|固定总量 Sigmoid Top-N；阈值隐式梯度；逐 N 需求目标及软/硬 TV|
|`maed/evaluation.py`|总体质量预算、学生 HarmRate、最差10%平均损失、最大损失及配对区间|
|`maed/diagnostics.py`|M1 全量评价；M2 矩阵扰动、真实模型参数方向探针及机制门槛|
|`maed/io.py`|独立源代码合同、输出锁定和 CSV|
|`scripts/run_maed_suite.py`|plan/M0/M1/M2/all-diagnostics 入口，默认仅显示计划，断点跳过已完成阶段|
|`tests/test_maed.py`|13 项数学、接口与恢复合同检查|

新增模块独立于 `debias/`，避免改变旧实验的 source_digest 和恢复合同。

## 3. 实际核查结果

### M0：来源与协议

- 三个数据集均记录 `all_observed_history`，当前只支持所提供历史末端的快照推荐解释，没有独立未来评价截点。
- 三者 Q-MIRT checkpoint 中的训练学生编号均与正式训练集合吻合。
- Eedi 保存 theta 为 52.19213450300739，按全体学生间隔重算完全吻合；训练学生单独标定为 51.570799568447775，不吻合。因此 Eedi 存在测试人群参与共享遗忘尺度标定的证据，应标明传导式预处理；这本身不等于使用了未来答案。
- Algebra2005、XES 当前副本缺少遗忘标定清单，来源仍待证实。
- EKTM checkpoint 记录 max_seq_len=200；本轮没有重放整个前处理训练和 mastery 导出过程，不声称已认证全部训练来源和序列截断行为。
- 保存距离与舍入存储状态重建距离的最大差异约为 Eedi 2.98e-8、Algebra2005 5.01e-7、XES 5.03e-7。容差明确为 1e-6，继续使用原全精度距离，不覆盖数据。

### M1：冻结 E0 的 Q 融合

固定 beta=0、0.25、0.5、1.0，clip=3；全部结果报告，不按测试成绩选 beta。主设置 beta=0.5。

Top-10 结果如下：

|数据集|E0 Ada|Q Ada|E0 NOV|Q NOV|E0 DED|Q DED|Q 全部 N 双指标预算通过数量|
|---|---:|---:|---:|---:|---:|---:|---:|
|Eedi|0.699120|0.710235|0.944743|0.938238|0.921368|0.712821|2/10|
|Algebra2005|0.738396|0.775301|0.956819|0.955962|0.542361|0.459722|9/10|
|XES|0.880361|0.892195|0.979632|0.976598|0.869710|0.792946|9/10|

Top-10 教育适配性和曝光存在改善，但不能仅看 Top-10 宣称达标：主设置三个数据集均有其他 N 未通过 Ada/NOV 双指标预算。每个 N 的原值、学生损失及全部 beta 见 CSV。

beta=0 导出的分数与原序列化概率完全一致；Ada/NOV/DED 回退一致。Ep 复算存在小于 2e-8 的数值差异，不宣称跨运行浮点逐位一致。

### M2：曝光代理

固定训练学生抽样48人、矩阵诊断16步；温度使用训练 logit 行中心化后的 IQR 乘0.5、1、2，主设置乘1。模型参数方向探针使用同一训练集合中的16人、三档预先登记的相对扰动。

|数据集|主温度矩阵门槛|模型方向门槛|自动进入M4|
|---|---|---|---|
|Eedi|未通过|未通过|否|
|Algebra2005|未通过|未通过|否|
|XES|未通过|未通过|否|

Eedi、XES 在温度系数0.5的自由矩阵探针上可改善软/硬曝光，但它不是预先指定的主设置，也不代表真实 ConvE 参数方向同样有效。完整温度、每步轨迹和真实模型探针均已保存。

测试还验证了一个方法限制：当不同学生的评分完全相同时，群体曝光损失会给出相同梯度，不能自行打破学生对称性。因此不能把可微代理代码正确等同于它已能改善个性化。

M2 仅使用训练学生的需求目标，不读取测试曝光目标。矩阵步修改的是评分副本；参数探针临时移动独立加载的模型副本并恢复，不创建 optimizer，不保存扰动模型。
