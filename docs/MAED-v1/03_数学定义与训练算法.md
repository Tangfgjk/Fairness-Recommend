# 03 MAED-v1数学定义与训练算法

规范日期：2026-10-24。以下是与实现逐项对应的技术规范；阶段四论文方法章节未启动。

## 1. 符号与基础评分

U_tr为训练学生集合，I为全题库，K(e)为习题e的非空KC集合；m_uk和f_ue分别是正式存储的掌握度、习题遗忘度。N集合固定为{5,10,…,50}。A为二值题目—KC关联矩阵，不是模块Q。

原ConvE三元组logit写为

\[
z_\theta(h,r,t)=\langle\operatorname{ConvE}(\mathbf h,\mathbf r),\mathbf t\rangle+b_t.
\]

对应`SemanticConvE.score_logits()`及`maed.scoring.score_rec()`，后者是全题库矩阵形式。

## 2. Q：教育需求感知评分

\[
M_{ue}=\prod_{k\in K(e)}m_{uk},\qquad
d_{ue}=\sqrt{(0.8-M_{ue})^2+(0.8-f_{ue})^2}.
\]

距离读取正式`stu2ex_recommend_full_precision.json`，并由`maed.state.education_distances/load_state`检查能否从正式状态重建，容差为1e-6。

尺度只用训练学生×全题库距离：

\[
c=\operatorname{median}(d_{ue}),\quad
a=\max\{Q_{.75}(d)-Q_{.25}(d),10^{-6}\},\quad u\in U_{tr}.
\]

\[
g_{ue}=-\operatorname{clip}\left((d_{ue}-c)/a,-3,3\right),\qquad
z^Q_{ue}=z_\theta(u,\mathrm{rec},e)+\beta g_{ue},\quad\beta=0.5.
\]

对应`EducationScale.fit/transform`、`fuse_logits`及`QScorer.fuse_triples/rec_logits`。Q项是固定先验，不是额外神经网络。监督BCE概率为sigmoid(zQ)；非rec保持原始logit。beta=0直接跳过融合计算。

## 3. D：需求参照曝光

令R_N(u)是按d从小到大、题目编号打破并列的规则Top-N。对均匀无放回抽取的辅助训练学生集合B，

\[
p^D_{B,N}(e)=\frac{1}{|B|N}\sum_{u\in B}\mathbb1\{e\in R_N(u)\}.
\]

每个N的目标分布和为1。B最多16人，独立于监督batch抽取，只允许训练学生。对应`ExposureObjective.__call__`、`EducationState.training_distance`和`rule_targets`。

这里的D是教育规则需求参照，不是独立观测的公平标签，也不是学习后的预测器。

## 4. E：边界校准软Top-N

温度参考分数是同轮冻结E0在**全部训练学生**上的z0+beta g。令Delta_uN为第N与N+1名的分差，只取正分差计算中位数：

\[
\tau_N=\max\{\operatorname{median}(\Delta_{uN}:\Delta_{uN}>0),\epsilon_\tau\}.
\]

无正分差时中位数项取0。对按学生行中心化的参考logit，令

\[
q=\max\{\operatorname{IQR}(z_{0}^{Q}-\overline z_{0,u}^{Q}),10^{-3}\},\quad
\epsilon_\tau=\max\{10^{-4}q,10^{-6}\}.
\]

温度倍率为1；每个N的温度标定一次后冻结，不用测试集或后续epoch调整。对应`calibrate_temperatures`。

对辅助前向的融合logit，

\[
w_{ue}^{(N)}=\sigma\left(\frac{z^Q_{ue}-\overline z^Q_u-t_{uN}}{\tau_N}\right),\qquad
\sum_e w_{ue}^{(N)}=N.
\]

阈值t以float64的64次二分求解，输出转换回logit dtype。设置a_e=w_e(1−w_e)/tau_N，隐式梯度为

\[
\frac{\partial w_e}{\partial z_j}
=a_e\left(\mathbb1\{e=j\}-\frac{a_j}{\sum_l a_l}\right).
\]

对应`_MultiTopN.forward/backward`；充分饱和时导数可能很弱，不能保证任一优化步必然改变硬Top-N。

\[
\widehat p_{B,N}(e)=\frac{1}{|B|N}\sum_{u\in B}w_{ue}^{(N)},\qquad
\mathcal L_E=\frac1{|\mathcal N|}\sum_{N\in\mathcal N}\frac12\sum_e
\left|\widehat p_{B,N}(e)-p^D_{B,N}(e)\right|.
\]

对应`calibrated_exposure_loss`。没有额外KC曝光损失；KC指标是评价输出，不应写成已优化独立KC损失。

## 5. 联合目标与执行方式

\[
\mathcal L_{BCE}=-\frac1{|T_b|}\sum_{(h,r,t,y)\in T_b}
\big[y\log p(h,r,t)+(1-y)\log(1-p(h,r,t))\big],
\]

其中rec的p使用融合logit，非rec的p使用原logit。实现沿用原概率BCE路径，不替换为新BPR。

\[
\mathcal L_{MAED}=\mathcal L_{BCE}+\lambda_E\mathcal L_E,\qquad\lambda_E=0.01.
\]

曝光项只在含rec的监督batch执行。M3的lambdaE=0，完全跳过曝光目标和采样。Ada/NOV预算是验收标准，不进入损失，也没有硬质量保证。

```text
读取并验证正式数据、同轮E0与固定评价来源
在训练学生上拟合教育尺度，冻结E0+Q逐N温度
设置seed2024，按原顺序构造原模型、负采样数据与Adam
若续跑，恢复上一完整epoch的权重、Adam与全部RNG
for epoch = 1..25:
    model.train()
    for 原DataLoader混合关系batch:
        L_BCE = 原负采样 + rec-only Q融合概率BCE
        if M4且含rec:
            B = 独立无放回抽取最多16位训练学生
            pD = 同批B的逐N规则曝光
            在冻结BN/Dropout行为且保留autograd的原生GRU前向中求zQ
            L_E = 逐N固定质量软曝光与pD的平均TV
        else: 跳过曝光采样和前向
        backward(L_BCE + lambdaE * L_E)
        原Adam.step()，每batch仅一次
    记录固定训练子集审计；按本轮监督BCE决定best
    保存last、Adam、Python/NumPy/Torch/CUDA及曝光采样器RNG
导出best与last测试分数；统一评价，各N取同一排序前缀
```

## 6. 实现边界

监督与辅助损失使用不同的BN/Dropout行为，是有意控制额外前向影响的训练策略，不应写成所有项在同一随机前向环境中计算。辅助过程不使用`no_grad()`，审计前向则使用。

训练每步新增全题库辅助打分，成本依赖16位学生、题库规模和10档N；本规范不声称已经完成论文级复杂度分析。阈值二分、矩阵打分和隐式梯度的代码事实均保留，正式复杂度推导属于暂缓的阶段四。
