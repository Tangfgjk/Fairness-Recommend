# 06 MAED-v1研究创新点与局限性

规范日期：2026-10-24。用于统一研究定位，不是论文方法章节或已完成外部文献新颖性审查。

## 1. 正式研究目标

> 在保留知识图谱推荐语义建模能力的基础上，使推荐曝光分布更接近学生教育需求参照，并缓解习题曝光集中及推荐列表同质化问题。

该目标中的“需求”由现有掌握度、遗忘度与KC结构定义；“参照”是规则，不是现实公平真值。暂不宣称消除全部频率偏好、实现因果去偏、全面优于R或获得真实学习提升。

## 2. 两部分核心技术设计

### 设计一：Q教育需求感知评分

在保留原SemanticConvE和监督协议的基础上，用掌握/遗忘教育距离构造训练尺度固定、范围受限的先验项，并在rec监督训练与全题库推断使用一致的logit融合。

其研究作用是让细粒度认知需求直接进入推荐评分。Q不新增学生编码网络，不等于自动去除流行度信息；Q-fixed、M3与E0提供不同层次的作用证据。

### 设计二：D+E教育需求参照的曝光优化

D把同一辅助训练学生集合的逐N规则推荐转成曝光目标；E用训练边界标定的固定质量可微Top-N，把真实排名附近的变化传回原模型，并通过平均TV曝光损失与原BCE联合训练。

D和E是目标建模及其优化机制，不包装成两个独立神经网络创新。不写入未实现的Ada/NOV硬约束、独立KC公平损失或测试期后处理。

这些是本项目的技术贡献候选；“首次”“优于所有已有方法”等外部新颖性/领先性主张尚无完整文献与实验支持。

## 3. 主张—证据对应

|主张|当前证据|可以说到哪里|
|---|---|---|
|Q改变教育适配评分|固定Q、M3相对E0的完整结果；训练/推断接口测试|固定先验有作用；训练增益并非全部指标一致|
|D/E有独立曝光增量|M4相比M3全部30个数据集×N位置的DED、Gini、Coverage改善|本seed、这些数据和规则参照下有效|

## 4. 主要局限

1. **单种子**：只完成seed2024；当前不扩2025/2026，不能声称随机稳定或跨seed显著性。
2. **规则依赖**：D、DED、RuleOverlap使用同一教育规则，指标间并非完全独立；规则偏差也可能传给模型。
3. **强R参照**：R在本轮全部N上Ada更高，覆盖/Gini也强。M4在部分模拟Ep、Algebra2005部分NOV有优势，研究价值需按取舍解释。
4. **局部频率偏好残留**：CFP仍高，XES较E0略升；core与训练rec频率相关仍强，不能宣称完全解耦或消除偏差。
5. **固定温度漂移**：后期Eedi/XES软硬对应变弱，当前策略仍有数值/优化边界。
6. **没有质量硬保证**：Ada/NOV预算不在损失中，平均质量不能保护每个学生。Algebra2005部分长列表NOV损失较大，虽已接受也必须报告。
7. **伪标签与训练目标**：rec50来自教育规则而非真实推荐后学习收益；不得把其拟合解释为已观察到的教育增益。
8. **历史快照与预处理**：使用完整已观察历史，Eedi存在传导式共享校准，其他数据集部分预处理来源有限；不能声称严格未来或完全归纳评估。
9. **模拟Ep**：冻结KT/readout模拟而非真实推荐后的作答和学习效果；少数Ep优势不等于实证学习优势。
10. **消融覆盖有限**：已有E0/Q-fixed/M3/M4不等于完成无Q曝光组等全部组合；机制分解也不是因果消融。
11. **工程可复现范围**：原deterministic=false保留，尚不保证跨硬件逐位相同；数据与模型不在Git，必须独立备份。
