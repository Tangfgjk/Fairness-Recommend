## 3. 已得到支持的主要现象

1. 三数据集全部30个数据集×N位置，M4相比M3降低DED、Item/KC Gini，并增加Item/KC Coverage及列表Jaccard距离。曝光改善发生在真实推荐列表，不仅是软损失下降。
2. Eedi的M4相比M3，Ada、NOV、Ep全部10档改善。XES的Ada、Ep全部改善，NOV全部略降但在原参考预算内。
3. Algebra2005的M4相比M3，Ada和NOV全部较低，但曝光指标改善；相比E0，Ada全部仍在0.01下降预算内，Top10提升约0.0392。不能称所有N的Ada均提升，Top50约下降0.0043。
4. Q-fixed到M3的提升较小且不统一，不能把M4的大幅收益全部解释为Q本身。

Algebra2005 Top50 NOV损失主要对应历史答对KC交集增加：精确记账项约−0.051784，加上并集变化约+0.000997，得到总−0.050787；kc74、kc89是较大负向新增已答对KC项。历史答对KC可能仍有复习需要，NOV下降不自动等同教育质量下降。

严格NOV损失>0.03为82/144；uid436、uid568恰为−3/100，原浮点统计因−0.030000000000000027记为84人。新审计单列精确边界，原表保留。最差10%学生平均NOV损失约0.167903、最大0.222316，说明不能用群体均值替代个体风险。

## 8. 可用于写作的当前结论

MAED-v1在seed2024上相对原学习模型有明确的教育适配/实际曝光改进与可解释的指标取舍，是当前主候选。尚无多种子稳定性、现实学习改善或完全频率解耦的证据。冻结不改变这些证据边界。
