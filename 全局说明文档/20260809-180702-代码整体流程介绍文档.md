# 代码整体流程介绍文档

生成时间：2026-08-09 18:07:02  
更新说明：已按当前代码清理结果更新 2CKG4ER 命名、Ada 指标、固定 raw 规则和 `triples.txt` 训练协议。

## 1. 总体数据流

```text
Data_Fin/<dataset>/raw 或 raw_compact
  -> front_pipeline 生成 front_features
  -> build_er_graph 生成 er_graph
  -> codes-New-ConvE 训练/测试 2CKG4ER
  -> comparison_models 训练/测试对比模型
  -> evaluate/summarize/report 输出 Ada、NOV、Ep_sim 和图表
```

正式 raw 规则固定为：

```text
assist2009-sub -> raw_compact
XES3G5M-sub-small -> raw_compact
其他数据集 -> raw
```

## 2. Raw 层

入口：

```text
raw_pipeline/build_raw_datasets.py
raw_pipeline/validate_raw_datasets.py
```

主要文件：

```text
interactions_all.csv
student_split.csv
Q.txt
exercise_metadata.json
concept_metadata.json
evaluation_uid_kc_response.txt
raw_manifest.json
```

raw 层只保存规范化输入，不保存学习到的模型参数。

## 3. Front Pipeline

一键入口：

```powershell
python front_pipeline\run_front_pipeline.py `
  --datasets Eedi,algebra2005,assist2009-sub,statics2011,XES3G5M-sub-small `
  --data-fin-root Data_Fin `
  --mirt-epochs 70 `
  --ektm-epochs 30 `
  --device cuda `
  --force
```

阶段顺序：

```text
prepare -> mirt -> ektm -> forgetting -> semantic -> graph -> validate
```

关键输出：

```text
Data_Fin/<dataset>/front_features/protocol.json
Data_Fin/<dataset>/front_features/mirt/*.npy
Data_Fin/<dataset>/front_features/stu2know_mastery.json
Data_Fin/<dataset>/front_features/stu2know_forget.json
Data_Fin/<dataset>/front_features/stu2ex_forget.json
Data_Fin/<dataset>/front_features/semantic_kg_features/
```

`train_ektm_mirt.py` 使用本目录内的 `ektm_mirt_components.py`，不再调用 `v11_pipeline`。

## 4. ER Graph

入口：

```text
front_pipeline/build_er_graph.py
```

输出：

```text
Data_Fin/<dataset>/er_graph/
  entities.dict
  relations.dict
  Q.txt
  triples.txt
  test_triples.txt
  stu2know_mastery.json
  stu2know_forget.json
  stu2ex_forget.json
  stu2ex_recommend.json
  stu2ex_recommend_full_precision.json
  semantic_kg_features/
```

`triples.txt` 包含训练学生的 `mlkc`、`exfr` 和 top-k `rec` 正例。  
`test_triples.txt` 只包含测试学生的 `mlkc`、`exfr`，不包含 `rec` 正例。

## 5. 2CKG4ER 训练与测试

入口：

```text
codes-New-ConvE/run_semantic_experiments.py
```

典型命令：

```powershell
python codes-New-ConvE\run_semantic_experiments.py `
  --dataset Eedi `
  --data-root Data_Fin `
  --graph-subdir er_graph `
  --run-id Eedi_vfin8_2ckg4er_3seeds `
  --seeds 2024,2025,2026 `
  --ablations all `
  --epochs 25 `
  --bs 1024 `
  --learning-rate 0.001 `
  --negative-ratio 5 `
  --cuda auto
```

内部调用：

```text
run_semantic_conve.py       训练 2CKG4ER
test_semantic_conve.py      导出 uid-ex scores
evaluate_recommendations.py 计算 Ada/NOV/Ep_sim
```

输出结构：

```text
runs/<dataset>/<run-id>/
  2CKG4ER/
    seed2024/
      best.pt
      last.pt
      metrics.json
      2CKG4ER_uid_ex_scores.pkl
      2ckg4er_inference.json
      eval/metrics.json
```

训练阶段固定只读 `triples.txt`。旧的 include/exclude test triples 参数已删除。

## 6. 对比模型流程

入口：

```text
comparison_models/run_v9_comparison_experiments.py
```

典型命令：

```powershell
python comparison_models\run_v9_comparison_experiments.py `
  --dataset Eedi `
  --data-root Data_Fin `
  --graph-subdir er_graph `
  --run-id Eedi_vfin8_comparison_3seeds `
  --seeds 2024,2025,2026 `
  --models all `
  --cuda auto
```

对比模型同样训练只读 `triples.txt`，测试/评价读取 `test_triples.txt`。
